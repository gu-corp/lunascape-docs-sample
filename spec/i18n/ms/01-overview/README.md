# 1. Gambaran keseluruhan

## 1.1 Tujuan

Orbit ialah perkhidmatan yang menyegerakkan nota teks biasa yang disunting pada beberapa peranti, tanpa sebarang tindakan daripada pengguna. Dokumen ini menetapkan fungsi, antara muka luaran dan kekangannya.

Bab ini seterusnya menetapkan [skop dan andaian](scope.md) serta [istilah](terms.md).
