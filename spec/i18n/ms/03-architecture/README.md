# 3. Seni bina

Penyegerakan terbentuk daripada empat elemen: klien, API penyegerakan, stor dan pemberitahuan ([komponen](components.md)). [Aliran penyegerakan](sync-flow.md) menunjukkan susunan perjalanan sesuatu perubahan dari peranti ke pelayan, dan dari pelayan ke peranti lain. Susunan itu bersandar pada [nombor versi](versioning.md); cara mengendalikan dua kemas kini yang tiba pada versi yang sama ditetapkan dalam [penyelesaian konflik](conflicts.md).
