# 4. API

Setiap titik akhir berpangkalan pada `https://api.orbit.example/v1` dan memerlukan `Authorization: Bearer <token>`. Badan mesej ialah JSON (UTF-8).

- [Titik akhir](endpoints.md) — senarainya, serta keperluan yang dipenuhi oleh setiap satu
- [Permintaan dan respons](push.md) — contoh badan mesej bagi `POST /notes/push`
- [Ralat](errors.md) — kod status dan tindakan peranti terhadapnya
