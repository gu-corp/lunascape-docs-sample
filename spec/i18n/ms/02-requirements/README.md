# 2. Keperluan

Keperluan dikenal pasti dengan ID, disertakan dengan keutamaan dan kaedah pengesahan. [Keperluan fungsian](functional.md) menerangkan gelagat yang kelihatan kepada pengguna; [keperluan bukan fungsian](non-functional.md) menetapkan sasaran bagi prestasi, ketersediaan dan keselamatan. Setiap keperluan dipetakan kepada komponen seni bina dan API melalui [kebolehjejakan keperluan](traceability.md).
