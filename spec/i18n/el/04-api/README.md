# 4. API

Όλα τα τελικά σημεία έχουν ως βάση το `https://api.orbit.example/v1` και απαιτούν `Authorization: Bearer <token>`. Το σώμα του μηνύματος είναι JSON (UTF-8).

- [Τελικά σημεία](endpoints.md) — ο κατάλογος και η απαίτηση που εξυπηρετεί το καθένα
- [Αίτημα και απόκριση](push.md) — παράδειγμα σώματος για `POST /notes/push`
- [Σφάλματα](errors.md) — κωδικοί κατάστασης και πώς τους αντιμετωπίζει η συσκευή
