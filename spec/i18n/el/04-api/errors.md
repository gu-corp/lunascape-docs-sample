# 4.3 Σφάλματα

| Κατάσταση | Σημασία | Ενέργεια της συσκευής |
|---|---|---|
| 400 | Λανθασμένη μορφή αιτήματος | Διακοπή αποστολής και καταγραφή |
| 401 | Μη έγκυρο διακριτικό | Εκ νέου έλεγχος ταυτότητας |
| 409 | Ασυμφωνία έκδοσης (διένεξη) | Αντικατάσταση με το `body` της απόκρισης και εμφάνιση διένεξης |
| 413 | Σώμα μεγαλύτερο από 1 MB | Ενημέρωση του χρήστη, χωρίς αποστολή |
| 429 | Υπερβολικά πολλά αιτήματα | Αναμονή για τα δευτερόλεπτα του `Retry-After` και εκ νέου αποστολή |
| 5xx | Βλάβη του διακομιστή | Εκ νέου αποστολή με εκθετική υποχώρηση (έως 5 φορές) |
