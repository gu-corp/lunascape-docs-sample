# 4.1 Σημεία πρόσβασης

| Μέθοδος | Διαδρομή | Σκοπός | Απαίτηση |
|---|---|---|---|
| POST | `/notes/push` | Αποστολή αλλαγής σε σημείωση | REQ-001, REQ-002 |
| GET | `/notes/pull?since=<version>` | Λήψη αλλαγών μετά από την καθορισμένη έκδοση | REQ-001 |
| DELETE | `/notes/{id}` | Διαγραφή σημείωσης (στον κάδο απορριμμάτων) | REQ-005 |
| POST | `/notes/{id}/restore` | Επαναφορά σημείωσης από τον κάδο απορριμμάτων | REQ-005 |
