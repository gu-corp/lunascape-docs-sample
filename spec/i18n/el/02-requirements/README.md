# 2. Απαιτήσεις

Οι απαιτήσεις προσδιορίζονται με αναγνωριστικό και συνοδεύονται από προτεραιότητα και μέθοδο επαλήθευσης. Οι [λειτουργικές απαιτήσεις](functional.md) περιγράφουν τη συμπεριφορά που βλέπει ο χρήστης· οι [μη λειτουργικές απαιτήσεις](non-functional.md) ορίζουν τιμές-στόχους για τις επιδόσεις, τη διαθεσιμότητα και την ασφάλεια. Κάθε απαίτηση αντιστοιχίζεται σε δομικά στοιχεία και σε API μέσω της [ιχνηλασιμότητας απαιτήσεων](traceability.md).
