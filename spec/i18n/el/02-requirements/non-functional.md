# 2.2 Μη λειτουργικές απαιτήσεις

| ID | Απαίτηση | Στόχος |
|---|---|---|
| NFR-001 | Χρόνος απόκρισης του API συγχρονισμού | Έως 300 ms στο 95ο εκατοστημόριο |
| NFR-002 | Διαθεσιμότητα | 99,9 % ανά μήνα |
| NFR-003 | Προστασία της επικοινωνίας | TLS 1.3. Το σώμα των σημειώσεων κρυπτογραφείται κατά την αποθήκευση στον διακομιστή |
| NFR-004 | Αριθμός σημειώσεων ανά χρήστη | Οι απαιτήσεις επιδόσεων ισχύουν έως 100.000 σημειώσεις |
