# 1. Επισκόπηση

## 1.1 Σκοπός

Το Orbit συγχρονίζει σημειώσεις απλού κειμένου που επεξεργάζονται σε πολλές συσκευές, χωρίς καμία ενέργεια από τον χρήστη. Το παρόν έγγραφο ορίζει τις λειτουργίες του, τις εξωτερικές διεπαφές και τους περιορισμούς του.

Το κεφάλαιο αυτό ορίζει στη συνέχεια το [πεδίο εφαρμογής και τις παραδοχές](scope.md) καθώς και τους [όρους](terms.md).
