# 1.2 Εύρος και προϋποθέσεις

## Εύρος

| Αρ. | Εντός εύρους | Εκτός εύρους |
|---|---|---|
| 1 | Συγχρονισμός δημιουργίας, ενημέρωσης και διαγραφής σημειώσεων | Συνεργατική επεξεργασία σημειώσεων (κοινή χρήση δρομέα κατά την ταυτόχρονη επεξεργασία) |
| 2 | Εντοπισμός και επίλυση διενέξεων μεταξύ συσκευών | Ο συντάκτης εντός της συσκευής |
| 3 | API συγχρονισμού (HTTP) | Χρεώσεις, διαχείριση λογαριασμού |

## Προϋποθέσεις

- Οι συσκευές συνδέονται μόνο διακεκομμένα. Η επεξεργασία εκτός σύνδεσης θεωρείται δεδομένη.
- Το σώμα μιας σημείωσης έχει ανώτατο όριο 1 MB.
- Η σειρά δεν εξαρτάται από το ρολόι της συσκευής· την καθορίζουν οι αριθμοί έκδοσης του διακομιστή.
