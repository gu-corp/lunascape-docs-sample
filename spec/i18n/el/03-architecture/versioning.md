# 3.3 Αριθμοί έκδοσης

Ο αριθμός έκδοσης είναι ένας μονότονα αύξων ακέραιος που αποδίδει ο διακομιστής ανά σημείωση. Η συσκευή στέλνει την τελευταία έκδοση που έλαβε ως `baseVersion`. Όταν η τρέχουσα έκδοση του διακομιστή δεν συμφωνεί με το `baseVersion`, πρόκειται για διένεξη (REQ-003). Τα ρολόγια των συσκευών δεν χρησιμοποιούνται για τον καθορισμό της σειράς ([ORB-ADR-0001](../05-decisions/0001-sync-method.md)).
