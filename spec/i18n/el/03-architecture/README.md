# 3. Αρχιτεκτονική

Ο συγχρονισμός αποτελείται από τέσσερα στοιχεία: τον πελάτη, το API συγχρονισμού, τον αποθηκευτικό χώρο και τις ειδοποιήσεις ([δομικά στοιχεία](components.md)). Η [ροή του συγχρονισμού](sync-flow.md) δείχνει τη σειρά με την οποία μια αλλαγή φτάνει από μια συσκευή στον διακομιστή και από τον διακομιστή στις υπόλοιπες συσκευές. Η σειρά αυτή στηρίζεται στους [αριθμούς έκδοσης](versioning.md), ενώ ο τρόπος αντιμετώπισης δύο ενημερώσεων που αφορούν την ίδια έκδοση ορίζεται στην [επίλυση διενέξεων](conflicts.md).
