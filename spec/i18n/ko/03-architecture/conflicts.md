# 3.4 충돌 해결

| 경우 | 규칙 |
|---|---|
| 같은 줄을 각각 따로 변경한 경우 | 양쪽 변경을 모두 남기고, 나중에 도착한 쪽을 `>>>` 로 구분하여 끝에 덧붙인다. 사용자에게 충돌이 있음을 표시한다(REQ-006) |
| 서로 다른 줄을 변경한 경우 | 3방향 병합으로 자동으로 통합한다. 사용자에게는 알리지 않는다 |
| 한쪽이 삭제한 경우 | 삭제를 우선하고, 다른 한쪽의 내용은 휴지통에 넣는다(REQ-005) |

어느 경우에도 내용을 잃지 않는다(REQ-004).
