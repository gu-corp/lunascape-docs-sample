# 4.3 오류

| 상태 | 의미 | 단말의 대응 |
|---|---|---|
| 400 | 요청 형식이 잘못됨 | 전송을 중단하고 로그에 남긴다 |
| 401 | 토큰이 무효함 | 다시 인증한다 |
| 409 | 버전 불일치(충돌) | 응답의 `body`로 바꾸고 충돌이 있음을 표시한다 |
| 413 | 본문이 1 MB를 초과함 | 사용자에게 알리고 전송하지 않는다 |
| 429 | 요청이 너무 많음 | `Retry-After`의 초만큼 기다렸다가 다시 보낸다 |
| 5xx | 서버 장애 | 지수 백오프로 다시 보낸다(최대 5회) |
