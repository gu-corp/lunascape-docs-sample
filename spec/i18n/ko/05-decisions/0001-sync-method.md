# ORB-ADR-0001: 동기화 방식을 "서버 채번 버전과 3방향 병합"으로 한다

| 항목 | 내용 |
|---|---|
| 문서 ID | ORB-ADR-0001 |
| 버전 | 1.0 |
| 갱신일 | 2026-07-01 |
| 상태 | 승인됨 |

## 1. 배경

오프라인에서 편집되는 여러 단말의 노트를 수렴시켜야 한다. 후보는 (a) 최종 갱신 시각이 이기는 방식, (b) CRDT, (c) 서버가 채번하는 버전 번호와 3방향 병합의 세 가지였다.

## 2. 결정

| 항번 | 결정 사항 |
|---|---|
| 1 | 순서는 서버가 채번하는 버전 번호로 정한다. 단말의 시계는 신뢰하지 않는다 |
| 2 | 충돌은 3방향 병합으로 해결하고, 해결할 수 없는 행은 양쪽을 모두 남긴다. 내용을 잃지 않는 것을 우선한다 |
| 3 | CRDT는 채택하지 않는다. 노트는 짧고 동시 편집 요구가 없으며, 본문 크기가 2배 이상이 되는 대가에 걸맞지 않기 때문이다 |

## 3. 영향

| 항번 | 영향 |
|---|---|
| 1 | 단말은 `baseVersion`을 보관하고, 전송할 때마다 함께 보낸다 |
| 2 | 충돌 표시(REQ-006)가 단말의 필수 기능이 된다 |
| 3 | 서버는 최근 30일의 이력을 보관한다(휴지통과 3방향 병합의 기준을 위해) |
