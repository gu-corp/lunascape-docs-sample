# 4. API

Всички крайни точки се основават на `https://api.orbit.example/v1` и изискват `Authorization: Bearer <token>`. Телата са във формат JSON (UTF-8).

- [Крайни точки](endpoints.md) — списъкът и съответстващите изисквания
- [Заявка и отговор](push.md) — пример за тяло на `POST /notes/push`
- [Грешки](errors.md) — кодове на състоянието и действията на устройството
