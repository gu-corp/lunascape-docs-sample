# 4.3 Грешки

| Състояние | Значение | Какво прави устройството |
|---|---|---|
| 400 | Неправилен формат на заявката | Спира изпращането и го записва в дневника |
| 401 | Невалиден токен | Извършва повторно удостоверяване |
| 409 | Несъответствие на версиите (конфликт) | Заменя с `body` от отговора и показва конфликт |
| 413 | Тялото надхвърля 1 MB | Съобщава на потребителя и не изпраща |
| 429 | Твърде много заявки | Изчаква секундите, посочени в `Retry-After`, и изпраща отново |
| 5xx | Неизправност на сървъра | Изпраща отново с експоненциално изчакване (до 5 пъти) |
