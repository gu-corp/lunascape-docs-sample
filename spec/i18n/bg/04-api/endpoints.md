# 4.1 Крайни точки

| Метод | Път | Предназначение | Изискване |
|---|---|---|---|
| POST | `/notes/push` | Изпраща промяна в бележка | REQ-001, REQ-002 |
| GET | `/notes/pull?since=<version>` | Получава промените след указаната версия | REQ-001 |
| DELETE | `/notes/{id}` | Изтрива бележка (в кошчето) | REQ-005 |
| POST | `/notes/{id}/restore` | Възстановява бележка от кошчето | REQ-005 |
