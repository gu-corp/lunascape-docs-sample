# 1. Общ преглед

## 1.1 Предназначение

Orbit е услуга, която синхронизира бележки в обикновен текст, редактирани на няколко устройства, без действие от страна на потребителя. Настоящият документ определя нейните функции, външни интерфейси и ограничения.

Тази глава продължава с определянето на [обхвата и предпоставките](scope.md) и на [термините](terms.md).
