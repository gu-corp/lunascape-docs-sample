# 2. Изисквания

Изискванията се идентифицират с ID и към тях се добавят приоритет и метод за проверка. [Функционалните изисквания](functional.md) описват поведението, видимо за потребителя; [нефункционалните изисквания](non-functional.md) задават целеви стойности за производителност, наличност и безопасност. Всяко изискване се съотнася към компонентите на архитектурата и към API чрез [проследимостта на изискванията](traceability.md).
