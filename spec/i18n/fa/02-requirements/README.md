# ۲. نیازمندی‌ها

نیازمندی‌ها با شناسه مشخص می‌شوند و اولویت و روش تأیید به آن‌ها پیوست می‌شود. [نیازمندی‌های کارکردی](functional.md) رفتاری را توصیف می‌کنند که برای کاربر دیده می‌شود؛ [نیازمندی‌های غیرکارکردی](non-functional.md) مقادیر هدف برای کارایی، در دسترس بودن و ایمنی را تعیین می‌کنند. هر نیازمندی از طریق [ردیابی نیازمندی‌ها](traceability.md) به اجزای سازنده و API نگاشت می‌شود.
