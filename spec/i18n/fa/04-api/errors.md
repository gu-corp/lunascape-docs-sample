# ۴.۳ خطاها

| وضعیت | معنا | کاری که دستگاه انجام می‌دهد |
|---|---|---|
| 400 | قالب درخواست نادرست است | ارسال را متوقف کنید و آن را در گزارش ثبت کنید |
| 401 | توکن نامعتبر است | دوباره احراز هویت کنید |
| 409 | ناسازگاری نسخه (تعارض) | با `body` پاسخ جایگزین کنید و وجود تعارض را نشان دهید |
| 413 | حجم بدنه بیش از ۱ مگابایت است | به کاربر اطلاع دهید و ارسال نکنید |
| 429 | تعداد درخواست‌ها بیش از حد است | به اندازهٔ ثانیه‌های ذکرشده در `Retry-After` صبر کنید و دوباره بفرستید |
| 5xx | خرابی سرور | با عقب‌نشینی نمایی دوباره بفرستید (حداکثر ۵ بار) |
