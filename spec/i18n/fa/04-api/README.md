# ۴. API

همهٔ نقطه‌های پایانی بر پایهٔ `https://api.orbit.example/v1` هستند و `Authorization: Bearer <token>` را الزامی می‌کنند. بدنهٔ پیام JSON (UTF-8) است.

- [نقطه‌های پایانی](endpoints.md) — فهرست و نیازمندی متناظر با هر یک
- [درخواست و پاسخ](push.md) — نمونهٔ بدنهٔ `POST /notes/push`
- [خطاها](errors.md) — کدهای وضعیت و اقدام دستگاه
