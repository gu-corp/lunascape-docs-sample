# ۳. معماری

همگام‌سازی از چهار عنصر تشکیل می‌شود: کلاینت، API همگام‌سازی، انبارک و اعلان‌ها ([اجزای سازنده](components.md)). ترتیبی که یک تغییر از دستگاه به سرور و از سرور به دستگاه‌های دیگر می‌رسد، در [جریان همگام‌سازی](sync-flow.md) نشان داده شده است. مبنای این ترتیب [شماره‌های نسخه](versioning.md) است و نحوهٔ رسیدگی به دو به‌روزرسانی که روی یک نسخهٔ یکسان قرار می‌گیرند، در [حل تعارض](conflicts.md) تعریف شده است.
