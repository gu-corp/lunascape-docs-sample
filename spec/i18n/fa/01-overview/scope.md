# ۱.۲ دامنه و پیش‌فرض‌ها

## دامنه

| ردیف | در دامنه | خارج از دامنه |
|---|---|---|
| ۱ | همگام‌سازی ایجاد، به‌روزرسانی و حذف یادداشت | ویرایش مشارکتی یادداشت (اشتراک مکان‌نما در ویرایش هم‌زمان) |
| ۲ | تشخیص و رفع تعارض میان دستگاه‌ها | ویرایشگر درون دستگاه |
| ۳ | API همگام‌سازی (HTTP) | صورت‌حساب و مدیریت حساب |

## پیش‌فرض‌ها

- دستگاه‌ها تنها به‌صورت متناوب متصل می‌شوند. ویرایش به‌صورت برون‌خط پیش‌فرض است.
- حجم متن هر یادداشت حداکثر ۱ مگابایت است.
- ترتیب به ساعت دستگاه وابسته نیست؛ شمارهٔ نسخهٔ سرور آن را تعیین می‌کند.
