# ۱. مرور کلی

## ۱.۱ هدف

Orbit سرویسی است که یادداشت‌های متن سادهٔ ویرایش‌شده در چند دستگاه را بدون هیچ اقدامی از سوی کاربر همگام‌سازی می‌کند. این سند، کارکردها، واسط‌های بیرونی و محدودیت‌های آن را تعریف می‌کند.

این فصل در ادامه، [دامنه و پیش‌فرض‌ها](scope.md) و [اصطلاحات](terms.md) را تعریف می‌کند.
