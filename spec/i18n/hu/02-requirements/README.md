# 2. Követelmények

A követelményeket azonosító jelöli, és minden követelményhez tartozik egy prioritás és egy ellenőrzési módszer. A [funkcionális követelmények](functional.md) a felhasználó számára látható viselkedést írják le, a [nem funkcionális követelmények](non-functional.md) pedig a teljesítményre, a rendelkezésre állásra és a biztonságra vonatkozó célértékeket rögzítik. Az egyes követelményeket a [követelmények nyomonkövetése](traceability.md) rendeli hozzá az egyes komponensekhez és API-khoz.
