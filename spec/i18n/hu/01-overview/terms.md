# 1.3 Fogalmak

| Fogalom | Meghatározás |
|---|---|
| Jegyzet | Egyetlen szövegfájl, amelyhez azonosító, törzsszöveg, módosítási idő és verziószám tartozik |
| Eszköz | Az Orbit klienst futtató gép, amelyet az eszközazonosító azonosít |
| Verzió | Egész szám, amely minden módosításkor eggyel nő; a kiosztása a kiszolgáló feladata |
| Ütközés | Két eszköz egymástól függetlenül módosította a jegyzet azonos verzióját |
| Konvergencia | Minden eszközön ugyanaz a jegyzet tartalma |
