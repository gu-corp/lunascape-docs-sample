# 1. Áttekintés

## 1.1 Cél

Az Orbit a több eszközön szerkesztett egyszerű szöveges jegyzeteket a felhasználó beavatkozása nélkül szinkronizálja. Ez a dokumentum meghatározza a szolgáltatás funkcióit, külső interfészeit és korlátait.

Ez a fejezet a továbbiakban meghatározza a [hatókört és az előfeltevéseket](scope.md), valamint a [fogalmakat](terms.md).
