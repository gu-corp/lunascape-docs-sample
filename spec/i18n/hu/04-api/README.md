# 4. API

Minden végpont a `https://api.orbit.example/v1` címen alapul, és megköveteli az `Authorization: Bearer <token>` fejlécet. A törzs JSON (UTF-8) formátumú.

- [Végpontok](endpoints.md) — a lista és a hozzájuk tartozó követelmények
- [Kérés és válasz](push.md) — példa a `POST /notes/push` törzsére
- [Hibák](errors.md) — állapotkódok és a készülék teendői
