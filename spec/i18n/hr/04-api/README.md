# 4. API

Sve krajnje točke imaju korijen na `https://api.orbit.example/v1` i zahtijevaju `Authorization: Bearer <token>`. Tijela su JSON (UTF-8).

- [Krajnje točke](endpoints.md) — popis i zahtjev kojemu svaka služi
- [Zahtjev i odgovor](push.md) — primjer tijela za `POST /notes/push`
- [Pogreške](errors.md) — statusni kodovi i što uređaj poduzima
