# 2. Zahtjevi

Zahtjevi se identificiraju po ID-u, uz priložen prioritet i metodu provjere. [Funkcionalni zahtjevi](functional.md) opisuju ponašanje vidljivo korisniku, a [nefunkcionalni zahtjevi](non-functional.md) postavljaju ciljne vrijednosti za performanse, dostupnost i sigurnost. Svaki se zahtjev povezuje s komponentama arhitekture i API-jem putem [praćenja zahtjeva](traceability.md).
