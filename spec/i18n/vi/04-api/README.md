# 4. API

Mọi endpoint đều lấy `https://api.orbit.example/v1` làm gốc và yêu cầu `Authorization: Bearer <token>`. Phần thân là JSON (UTF-8).

- [Lỗi](errors.md) — mã trạng thái và cách thiết bị xử lý
