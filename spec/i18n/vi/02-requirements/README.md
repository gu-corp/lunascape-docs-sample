# 2. Yêu cầu

Yêu cầu được nhận biết bằng ID, kèm theo mức ưu tiên và phương pháp kiểm chứng. [Yêu cầu chức năng](functional.md) mô tả hành vi mà người dùng nhìn thấy; [yêu cầu phi chức năng](non-functional.md) đặt ra các giá trị mục tiêu về hiệu năng, tính sẵn sàng và tính an toàn. Mỗi yêu cầu được ánh xạ tới thành phần cấu trúc và API trong [truy vết yêu cầu](traceability.md).
