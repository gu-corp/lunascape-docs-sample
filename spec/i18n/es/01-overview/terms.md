# 1.3 Términos

| Término | Definición |
|---|---|
| Nota | Un archivo de texto, con un identificador, un cuerpo, una hora de actualización y un número de versión |
| Dispositivo | Un equipo en el que se ejecuta el cliente de Orbit; se identifica mediante un id de dispositivo |
| Versión | Un número entero que aumenta en uno con cada actualización de la nota; lo asigna el servidor |
| Conflicto | Situación en la que dos dispositivos actualizan por separado la misma versión de una nota |
| Convergencia | Situación en la que todos los dispositivos tienen la nota con el mismo contenido |
