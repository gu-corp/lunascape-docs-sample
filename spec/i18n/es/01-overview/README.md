# 1. Descripción general

## 1.1 Propósito

Orbit es un servicio que sincroniza notas de texto plano editadas en varios dispositivos, sin ninguna acción por parte del usuario. Este documento define sus funciones, sus interfaces externas y sus restricciones.

Este capítulo define a continuación el [alcance y los supuestos](scope.md) y los [términos](terms.md).
