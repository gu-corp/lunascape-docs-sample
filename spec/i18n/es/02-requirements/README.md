# 2. Requisitos

Los requisitos se identifican mediante un ID y llevan asociados una prioridad y un método de verificación. Los [requisitos funcionales](functional.md) describen el comportamiento visible para el usuario; los [requisitos no funcionales](non-functional.md) fijan los valores objetivo de rendimiento, disponibilidad y seguridad. Cada requisito se asocia con los componentes y las API mediante el [seguimiento de requisitos](traceability.md).
