# 2. Cerințe

Cerințele se identifică printr-un ID și au atașate o prioritate și o metodă de verificare. [Cerințele funcționale](functional.md) descriu comportamentul vizibil pentru utilizator, iar [cerințele nefuncționale](non-functional.md) stabilesc valorile-țintă pentru performanță, disponibilitate și siguranță. Fiecare cerință este pusă în corespondență cu componentele arhitecturii și cu API-urile prin [trasabilitatea cerințelor](traceability.md).
