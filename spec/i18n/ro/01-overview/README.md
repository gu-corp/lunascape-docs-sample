# 1. Prezentare generală

## 1.1 Scop

Orbit este un serviciu care sincronizează, fără nicio acțiune din partea utilizatorului, notițele în text simplu editate pe mai multe dispozitive. Documentul de față stabilește funcțiile, interfețele externe și restricțiile acestuia.

Acest capitol stabilește în continuare [domeniul de aplicare și premisele](scope.md), precum și [termenii](terms.md).
