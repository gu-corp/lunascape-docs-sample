# ORB-ADR-0001：同步方式采用"服务器采番的版本号与三方合并"

| 项目 | 内容 |
|---|---|
| 文档 ID | ORB-ADR-0001 |
| 版本 | 1.0 |
| 更新日期 | 2026-07-01 |
| 状态 | 已批准 |

## 1. 背景

需要让多台设备上离线编辑的笔记收敛为一致。候选方案有三个：(a) 以最后更新时间为准，(b) CRDT，(c) 服务器采番的版本号与三方合并。

## 2. 决定

| 序号 | 决定事项 |
|---|---|
| 1 | 顺序由服务器采番的版本号决定，不信任设备的时钟 |
| 2 | 冲突通过三方合并解决，无法解决的行同时保留双方内容。优先保证内容不丢失 |
| 3 | 不采用 CRDT。笔记篇幅短，没有同时编辑的需求，正文体积增大一倍以上的代价不值得 |

## 3. 影响

| 序号 | 影响 |
|---|---|
| 1 | 设备保存 `baseVersion`，并在每次发送时附带 |
| 2 | 冲突的显示（REQ-006）成为设备的必备功能 |
| 3 | 服务器保留最近 30 天的历史记录（用于回收站，以及作为三方合并的基准） |
