# 1.3 Termini

| Termine | Definizione |
|---|---|
| Nota | Un singolo file di testo, dotato di identificatore, corpo, ora di aggiornamento e numero di versione |
| Dispositivo | La macchina su cui gira il client Orbit; si identifica con un ID dispositivo |
| Versione | Numero intero che cresce di uno a ogni aggiornamento della nota; lo assegna il server |
| Conflitto | Stato in cui due dispositivi hanno aggiornato separatamente la stessa versione di una nota |
| Convergenza | Stato in cui tutti i dispositivi hanno la nota con lo stesso contenuto |
