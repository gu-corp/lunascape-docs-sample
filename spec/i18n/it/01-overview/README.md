# 1. Panoramica

## 1.1 Scopo

Orbit è un servizio che sincronizza le note in testo semplice modificate su più dispositivi, senza alcuna azione da parte dell'utente. Il presente documento ne definisce le funzioni, le interfacce esterne e i vincoli.

Questo capitolo prosegue definendo l'[ambito e i presupposti](scope.md) e i [termini](terms.md).
