# 2. Requisiti

I requisiti sono identificati da un ID, corredato di una priorità e di un metodo di verifica. I [requisiti funzionali](functional.md) descrivono il comportamento visibile all'utente; i [requisiti non funzionali](non-functional.md) fissano gli obiettivi di prestazioni, disponibilità e sicurezza. Ogni requisito è messo in corrispondenza con i componenti e le API tramite la [tracciabilità dei requisiti](traceability.md).
