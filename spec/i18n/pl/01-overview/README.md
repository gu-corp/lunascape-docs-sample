# 1. Przegląd

## 1.1 Cel

Orbit synchronizuje notatki w postaci zwykłego tekstu, edytowane na wielu urządzeniach, bez żadnego działania ze strony użytkownika. Niniejszy dokument określa jego funkcje, interfejsy zewnętrzne oraz ograniczenia.

W dalszej części tego rozdziału określono [zakres i założenia](scope.md) oraz [terminy](terms.md).
