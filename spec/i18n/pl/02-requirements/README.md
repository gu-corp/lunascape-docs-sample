# 2. Wymagania

Wymagania są identyfikowane za pomocą identyfikatora, z dołączonym priorytetem i metodą weryfikacji. [Wymagania funkcjonalne](functional.md) opisują zachowanie widoczne dla użytkownika, a [wymagania niefunkcjonalne](non-functional.md) określają wartości docelowe wydajności, dostępności i bezpieczeństwa. Każde wymaganie jest powiązane z elementami architektury i punktami końcowymi API poprzez [śledzenie wymagań](traceability.md).
