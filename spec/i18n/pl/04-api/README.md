# 4. API

Wszystkie punkty końcowe mają podstawę `https://api.orbit.example/v1` i wymagają nagłówka `Authorization: Bearer <token>`. Treść żądania jest w formacie JSON (UTF-8).

- [Punkty końcowe](endpoints.md) — lista wraz z odpowiadającymi im wymaganiami
- [Żądanie i odpowiedź](push.md) — przykładowa treść dla `POST /notes/push`
- [Błędy](errors.md) — kody stanu i sposób postępowania urządzenia
