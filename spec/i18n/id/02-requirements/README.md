# 2. Kebutuhan

Kebutuhan diidentifikasi dengan ID, disertai prioritas dan metode verifikasi. [Kebutuhan fungsional](functional.md) adalah perilaku yang terlihat oleh pengguna; [kebutuhan non-fungsional](non-functional.md) adalah nilai target untuk kinerja, ketersediaan dan keamanan. Setiap kebutuhan dipetakan ke komponen dan API melalui [penelusuran kebutuhan](traceability.md).
