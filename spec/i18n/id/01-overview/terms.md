# 1.3 Istilah

| Istilah | Definisi |
|---|---|
| Catatan | Satu berkas teks; memiliki pengenal, isi, waktu pembaruan, dan nomor versi |
| Perangkat | Mesin tempat klien Orbit berjalan; dikenali melalui ID perangkat |
| Versi | Bilangan bulat yang bertambah satu setiap kali catatan diperbarui; server yang menetapkannya |
| Konflik | Keadaan saat dua perangkat memperbarui versi catatan yang sama secara terpisah |
| Konvergensi | Keadaan saat semua perangkat memiliki isi catatan yang sama |
