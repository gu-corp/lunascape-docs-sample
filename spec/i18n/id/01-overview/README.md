# 1. Ikhtisar

## 1.1 Tujuan

Orbit adalah layanan yang menyinkronkan catatan teks biasa yang disunting di beberapa perangkat, tanpa tindakan apa pun dari pengguna. Dokumen ini menetapkan fungsi, antarmuka eksternal, dan batasannya.

Bab ini selanjutnya menetapkan [ruang lingkup dan asumsi](scope.md) serta [istilah](terms.md).
