# 4. API

Semua endpoint berakar pada `https://api.orbit.example/v1` dan memerlukan `Authorization: Bearer <token>`. Badan pesan berupa JSON (UTF-8).

- [Endpoint](endpoints.md) — daftarnya, beserta persyaratan yang dipenuhi masing-masing
- [Permintaan dan respons](push.md) — contoh badan pesan untuk `POST /notes/push`
- [Galat](errors.md) — kode status dan tindakan yang diambil perangkat
