# 2.1 功能需求

| ID | 需求 | 優先度 | 驗證方法 |
|---|---|---|---|
| REQ-001 | 在某台裝置上建立的筆記，於連線後 10 秒內送達其他裝置 | 必要 | 整合測試 |
| REQ-002 | 離線時編輯的筆記，在重新連線時自動送出 | 必要 | 整合測試 |
| REQ-003 | 對同一版本的兩筆更新會被偵測為衝突 | 必要 | 單元測試 |
| REQ-004 | 衝突依[3.4 的規則](../03-architecture/conflicts.md)自動解決，且不會遺失任一方的內容 | 必要 | 單元測試 |
| REQ-005 | 刪除會反映到其他裝置，並可在 30 天內從垃圾桶還原 | 建議 | 整合測試 |
| REQ-006 | 裝置可顯示同步狀態（已同步、傳送中、有衝突） | 建議 | 目視檢查 |
