# ORB-ADR-0001：同步方式採用「伺服器編號的版本與三方合併」

| 項目 | 內容 |
|---|---|
| 文件ID | ORB-ADR-0001 |
| 版本 | 1.0 |
| 更新日期 | 2026-07-01 |
| 狀態 | 已核准 |

## 1. 背景

必須讓在離線狀態下於多台裝置編輯的筆記收斂一致。候選方案有三個：(a) 以最後更新時刻為勝、(b) CRDT、(c) 伺服器編號的版本號搭配三方合併。

## 2. 決定

| 項次 | 決定事項 |
|---|---|
| 1 | 順序由伺服器編號的版本號決定，不信任裝置的時鐘 |
| 2 | 衝突以三方合併解決，無法解決的行則兩者都保留。優先確保內容不遺失 |
| 3 | 不採用 CRDT。筆記篇幅短，沒有同時編輯的需求，不值得付出內文大小增為兩倍以上的代價 |

## 3. 影響

| 項次 | 影響 |
|---|---|
| 1 | 裝置保存 `baseVersion`，並在每次傳送時一併附上 |
| 2 | 衝突的顯示（REQ-006）成為裝置的必要功能 |
| 3 | 伺服器保留最近 30 天的歷史記錄（供垃圾桶與三方合併的基底使用） |
