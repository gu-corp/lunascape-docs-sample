# 1.3 Käsitteet

| Käsite | Määritelmä |
|---|---|
| Muistiinpano | Yksi tekstitiedosto, jolla on tunnus, sisältö, muutosaika ja versionumero |
| Laite | Kone, jolla Orbit-asiakasohjelma toimii; tunnistetaan laitetunnuksella |
| Versio | Kokonaisluku, joka kasvaa yhdellä jokaisella päivityksellä; palvelin määrää sen |
| Ristiriita | Kaksi laitetta on päivittänyt muistiinpanon saman version toisistaan riippumatta |
| Suppeneminen | Kaikilla laitteilla on muistiinpanosta sama sisältö |
