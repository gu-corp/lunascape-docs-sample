# 1. Yleiskatsaus

## 1.1 Tarkoitus

Orbit synkronoi usealla laitteella muokattavat pelkkää tekstiä sisältävät muistiinpanot ilman käyttäjän toimenpiteitä. Tämä määrittely määrittelee sen toiminnot, ulkoiset rajapinnat ja rajoitukset.

Tässä luvussa määritellään seuraavaksi [laajuus ja oletukset](scope.md) sekä [termit](terms.md).
