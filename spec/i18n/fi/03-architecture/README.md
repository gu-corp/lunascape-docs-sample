# 3. Rakenne

Synkronointi muodostuu neljästä osasta: asiakassovellus, synkronointirajapinta, varasto ja ilmoitukset ([osat](components.md)). [Synkronoinnin kulku](sync-flow.md) esittää järjestyksen, jossa muutos siirtyy laitteelta palvelimelle ja palvelimelta muille laitteille. Järjestys perustuu [versionumeroihin](versioning.md), ja samaan versioon kohdistuvien päällekkäisten päivitysten käsittely määritellään kohdassa [ristiriitojen ratkaisu](conflicts.md).
