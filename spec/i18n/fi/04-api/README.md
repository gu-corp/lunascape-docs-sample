# 4. API

Kaikkien päätepisteiden juuri on `https://api.orbit.example/v1`, ja ne vaativat otsakkeen `Authorization: Bearer <token>`. Rungot ovat JSON-muotoisia (UTF-8).

- [Päätepisteet](endpoints.md) — luettelo ja kutakin vastaava vaatimus
- [Pyyntö ja vastaus](push.md) — esimerkki rungosta pyynnölle `POST /notes/push`
- [Virheet](errors.md) — tilakoodit ja päätelaitteen toimenpiteet
