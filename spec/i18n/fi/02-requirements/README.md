# 2. Vaatimukset

Vaatimukset tunnistetaan tunnuksen avulla, ja niihin liitetään prioriteetti ja todennusmenetelmä. [Toiminnalliset vaatimukset](functional.md) kuvaavat käyttäjälle näkyvän toiminnan; [ei-toiminnalliset vaatimukset](non-functional.md) asettavat tavoitearvot suorituskyvylle, käytettävyydelle ja turvallisuudelle. Jokainen vaatimus kytketään rakenneosiin ja API-rajapintoihin [vaatimusten jäljitettävyyden](traceability.md) avulla.
