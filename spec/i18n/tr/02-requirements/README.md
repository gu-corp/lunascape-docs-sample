# 2. Gereksinimler

Gereksinimler kimlik (ID) ile tanımlanır; her birine bir öncelik ve bir doğrulama yöntemi eklenir. [İşlevsel gereksinimler](functional.md) kullanıcının gördüğü davranışı, [işlevsel olmayan gereksinimler](non-functional.md) ise başarım, kullanılabilirlik ve güvenlik hedef değerlerini belirtir. Her gereksinim, [gereksinim izlenebilirliği](traceability.md) yoluyla mimari bileşenlere ve API uç noktalarına eşlenir.
