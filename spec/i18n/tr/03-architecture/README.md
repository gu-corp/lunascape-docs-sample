# 3. Mimari

Eşitleme dört öğeden oluşur: istemci, eşitleme API'si, depolama ve bildirimler ([bileşenler](components.md)). Bir değişikliğin cihazdan sunucuya, sunucudan diğer cihazlara hangi sırayla ulaştığı [eşitleme akışı](sync-flow.md) bölümünde gösterilir. Bu sıralama [sürüm numaralarına](versioning.md) dayanır; aynı sürüme gelen iki güncellemenin nasıl ele alınacağı [çakışma çözümü](conflicts.md) bölümünde tanımlanır.
