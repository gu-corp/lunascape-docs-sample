# 4. API

Tüm uç noktalar `https://api.orbit.example/v1` adresini temel alır ve `Authorization: Bearer <token>` ister. Gövde JSON (UTF-8) biçimindedir.

- [Uç noktalar](endpoints.md) — liste ve her birinin karşıladığı gereksinim
- [İstek ve yanıt](push.md) — `POST /notes/push` için örnek gövde
- [Hatalar](errors.md) — durum kodları ve cihazın yaptığı işlem
