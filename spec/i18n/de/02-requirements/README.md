# 2. Anforderungen

Anforderungen werden über eine ID identifiziert und mit einer Priorität sowie einem Nachweisverfahren versehen. [Funktionale Anforderungen](functional.md) beschreiben das für die Benutzer sichtbare Verhalten; [nichtfunktionale Anforderungen](non-functional.md) legen Zielwerte für Leistung, Verfügbarkeit und Sicherheit fest. Jede Anforderung wird über die [Nachverfolgbarkeit der Anforderungen](traceability.md) den Architekturbausteinen und den API-Endpunkten zugeordnet.
