# 4. API

Alle Endpunkte gehen von `https://api.orbit.example/v1` aus und erfordern `Authorization: Bearer <token>`. Der Rumpf ist JSON (UTF-8).

- [Endpunkte](endpoints.md) — die Liste und die jeweils zugehörige Anforderung
- [Anfrage und Antwort](push.md) — ein Beispielrumpf für `POST /notes/push`
- [Fehler](errors.md) — Statuscodes und wie das Gerät damit umgeht
