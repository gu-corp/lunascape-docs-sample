# 1. Überblick

## 1.1 Zweck

Orbit synchronisiert Notizen im Klartextformat, die auf mehreren Geräten bearbeitet werden, ohne Zutun des Benutzers. Dieses Dokument legt die Funktionen, die externen Schnittstellen und die Einschränkungen fest.

Dieses Kapitel bestimmt im Weiteren den [Geltungsbereich und die Annahmen](scope.md) sowie die [Begriffe](terms.md).
