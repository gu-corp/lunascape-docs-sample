# 1.3 Begriffe

| Begriff | Definition |
|---|---|
| Notiz | Eine einzelne Textdatei mit Kennung, Inhalt, Änderungszeit und Versionsnummer |
| Gerät | Ein Gerät, auf dem der Orbit-Client läuft; wird über die Gerätekennung identifiziert |
| Version | Eine ganze Zahl, die sich mit jeder Änderung einer Notiz um eins erhöht. Der Server vergibt sie |
| Konflikt | Zwei Geräte haben dieselbe Version einer Notiz unabhängig voneinander geändert |
| Konvergenz | Alle Geräte haben denselben Inhalt einer Notiz |
