# ৩. গঠন

সিঙ্ক চারটি উপাদান নিয়ে গঠিত: ক্লায়েন্ট, সিঙ্ক API, স্টোর এবং বিজ্ঞপ্তি ([উপাদানসমূহ](components.md))। একটি পরিবর্তন ডিভাইস থেকে সার্ভারে এবং সার্ভার থেকে অন্যান্য ডিভাইসে কোন ক্রমে পৌঁছায়, তা [সিঙ্কের প্রবাহ](sync-flow.md)-এ দেখানো হয়েছে। এই ক্রমের ভিত্তি হলো [সংস্করণ নম্বর](versioning.md); একই সংস্করণের উপর দুটি হালনাগাদ এসে পড়লে কীভাবে তা সামলানো হয়, সেটি [দ্বন্দ্ব নিরসন](conflicts.md)-এ নির্ধারণ করা আছে।
