# ১. সংক্ষিপ্ত বিবরণ

## ১.১ উদ্দেশ্য

Orbit হলো এমন একটি পরিষেবা, যা একাধিক ডিভাইসে সম্পাদিত প্লেইন-টেক্সট নোট ব্যবহারকারীর কোনো পদক্ষেপ ছাড়াই সমন্বয় করে। এই নথি তার কার্যাবলি, বহিঃস্থ ইন্টারফেস ও সীমাবদ্ধতা নির্ধারণ করে।

এই অধ্যায়ে এরপর [পরিসর ও পূর্বানুমান](scope.md) এবং [পরিভাষা](terms.md) নির্ধারণ করা হয়েছে।
