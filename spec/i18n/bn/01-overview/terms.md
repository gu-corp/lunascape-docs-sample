# ১.৩ পরিভাষা

| পরিভাষা | সংজ্ঞা |
|---|---|
| নোট | একটি টেক্সট ফাইল। এর একটি শনাক্তকারী, মূল লেখা, হালনাগাদের সময় ও সংস্করণ সংখ্যা থাকে |
| ডিভাইস | যে যন্ত্রে Orbit ক্লায়েন্ট চলে। ডিভাইস আইডি দিয়ে শনাক্ত করা হয় |
| সংস্করণ | নোট হালনাগাদ হলে প্রতিবার ১ করে বাড়ে এমন পূর্ণসংখ্যা। সার্ভার এটি নির্ধারণ করে |
| দ্বন্দ্ব | দুটি ডিভাইস একই সংস্করণের নোট আলাদাভাবে হালনাগাদ করেছে এমন অবস্থা |
| অভিসৃতি | সব ডিভাইসে নোটের বিষয়বস্তু এক হয়ে যাওয়ার অবস্থা |
