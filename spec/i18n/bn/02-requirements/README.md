# ২. প্রয়োজনীয়তা

প্রয়োজনীয়তাগুলি ID দিয়ে চিহ্নিত করা হয় এবং সেই সঙ্গে অগ্রাধিকার ও যাচাইয়ের পদ্ধতি যুক্ত থাকে। [কার্যকরী প্রয়োজনীয়তা](functional.md) হলো ব্যবহারকারীর কাছে দৃশ্যমান আচরণ, আর [অকার্যকরী প্রয়োজনীয়তা](non-functional.md) হলো কর্মক্ষমতা, প্রাপ্যতা ও নিরাপত্তার লক্ষ্যমাত্রা। প্রতিটি প্রয়োজনীয়তা [প্রয়োজনীয়তার অনুসরণ](traceability.md) অনুযায়ী গঠনউপাদান ও API-এর সঙ্গে মিলিয়ে দেওয়া হয়।
