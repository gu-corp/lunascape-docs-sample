# 2. Vereisten

Vereisten worden geïdentificeerd met een ID, met een prioriteit en een verificatiemethode erbij. [Functionele vereisten](functional.md) beschrijven het gedrag dat de gebruiker ziet; [niet-functionele vereisten](non-functional.md) leggen streefwaarden vast voor prestaties, beschikbaarheid en veiligheid. Elke vereiste wordt in [traceerbaarheid van vereisten](traceability.md) gekoppeld aan de architectuuronderdelen en de API.
