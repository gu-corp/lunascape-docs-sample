# 1.3 Begrippen

| Begrip | Definitie |
|---|---|
| Notitie | Eén tekstbestand, met een id, een tekst, een wijzigingstijd en een versienummer |
| Apparaat | Een machine waarop de Orbit-client draait; wordt aangeduid met een apparaat-id |
| Versie | Een geheel getal dat bij elke wijziging met één toeneemt; de server kent het toe |
| Conflict | Twee apparaten hebben dezelfde versie van een notitie onafhankelijk van elkaar gewijzigd |
| Convergentie | Alle apparaten hebben dezelfde inhoud van een notitie |
