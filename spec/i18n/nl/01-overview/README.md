# 1. Overzicht

## 1.1 Doel

Orbit synchroniseert platte-tekstnotities die op meerdere apparaten worden bewerkt, zonder dat de gebruiker iets hoeft te doen. Dit document legt de functies, externe interfaces en beperkingen ervan vast.

Dit hoofdstuk legt vervolgens het [bereik en de uitgangspunten](scope.md) en de [termen](terms.md) vast.
