# 1. Oversikt

## 1.1 Formål

Orbit er en tjeneste som synkroniserer rentekstnotater som redigeres på flere enheter, uten at brukeren foretar seg noe. Dette dokumentet fastsetter tjenestens funksjoner, eksterne grensesnitt og begrensninger.

Dette kapittelet fastsetter videre [omfang og forutsetninger](scope.md) og [termer](terms.md).
