# 4. API

Alle endepunkter har `https://api.orbit.example/v1` som utgangspunkt og krever `Authorization: Bearer <token>`. Meldingsinnholdet er JSON (UTF-8).

- [Forespørsel og svar](push.md) — eksempel på innhold for `POST /notes/push`
- [Feil](errors.md) — statuskoder og hva enheten gjør med dem
