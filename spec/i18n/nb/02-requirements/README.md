# 2. Krav

Krav identifiseres med ID, med en prioritet og en verifiseringsmetode tilknyttet. [Funksjonelle krav](functional.md) beskriver atferd som er synlig for brukeren; [ikke-funksjonelle krav](non-functional.md) angir målverdier for ytelse, tilgjengelighet og sikkerhet. Hvert krav knyttes til arkitekturkomponenter og API-er i [kravsporing](traceability.md).
