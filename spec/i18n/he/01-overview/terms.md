# 1.3 מונחים

| מונח | הגדרה |
|---|---|
| הערה | קובץ טקסט אחד, ובו מזהה, גוף, זמן עדכון ומספר גרסה |
| התקן | מכשיר שבו פועל הלקוח של Orbit; מזוהה במזהה התקן |
| גרסה | מספר שלם שגדל באחד בכל עדכון של ההערה. השרת מקצה אותו |
| התנגשות | שני התקנים עדכנו בנפרד את אותה גרסה של ההערה |
| התכנסות | כל ההתקנים מחזיקים את אותו תוכן של ההערה |
