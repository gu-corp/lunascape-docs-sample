# 2. דרישות

הדרישות מזוהות לפי מזהה, ולכל אחת מצורפות רמת עדיפות ושיטת אימות. [דרישות פונקציונליות](functional.md) מתארות התנהגות הנראית למשתמש, ו[דרישות לא־פונקציונליות](non-functional.md) קובעות ערכי יעד לביצועים, לזמינות ולבטיחות. כל דרישה ממופה לרכיבי הארכיטקטורה ולממשקי ה־API באמצעות [מעקב אחר דרישות](traceability.md).
