# 4.3 שגיאות

| מצב | משמעות | פעולת המכשיר |
|---|---|---|
| 400 | מבנה הבקשה שגוי | להפסיק את השליחה ולרשום ביומן |
| 401 | האסימון אינו תקף | לבצע אימות מחדש |
| 409 | אי-התאמה בין הגרסאות (התנגשות) | להחליף בערך `body` של התשובה ולהציג התנגשות |
| 413 | גוף הבקשה עולה על ‎1 MB | להודיע למשתמש ולא לשלוח |
| 429 | יותר מדי בקשות | להמתין את מספר השניות שב-`Retry-After` ולשלוח שוב |
| 5xx | תקלה בשרת | לשלוח שוב בהשהיה מעריכית (עד 5 פעמים) |
