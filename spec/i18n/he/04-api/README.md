# 4. API

כל נקודות הקצה מבוססות על `https://api.orbit.example/v1` ודורשות `Authorization: Bearer <token>`. גוף הבקשה הוא JSON‏ (UTF-8).

- [נקודות קצה](endpoints.md) — הרשימה, והדרישה שכל אחת מהן משרתת
- [בקשה ותגובה](push.md) — דוגמה לגוף של `POST /notes/push`
- [שגיאות](errors.md) — קודי מצב ומה עושה המכשיר בעקבותיהם
