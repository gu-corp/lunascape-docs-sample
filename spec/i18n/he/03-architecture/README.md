# 3. מבנה

הסנכרון מורכב מארבעה רכיבים: הלקוח, ממשק ה‑API של הסנכרון, המאגר וההתראות ([רכיבים](components.md)). [זרימת הסנכרון](sync-flow.md) מציגה את הסדר שבו שינוי עובר מהמכשיר אל השרת, ומהשרת אל שאר המכשירים. הסדר הזה נשען על [מספרי גרסה](versioning.md), והטיפול בשני עדכונים החלים על אותה גרסה מוגדר ב[יישוב התנגשויות](conflicts.md).
