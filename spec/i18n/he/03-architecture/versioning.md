# 3.3 מספרי גרסה

מספר הגרסה הוא מספר שלם עולה מונוטונית שהשרת מקצה לכל פתק. מכשיר שולח את הגרסה האחרונה שקיבל בתור `baseVersion`. כאשר הגרסה הנוכחית בשרת אינה תואמת את `baseVersion`, מדובר בהתנגשות (REQ-003). שעוני המכשירים אינם משמשים לקביעת הסדר ([ORB-ADR-0001](../05-decisions/0001-sync-method.md)).
