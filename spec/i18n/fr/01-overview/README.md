# 1. Présentation

## 1.1 Objet

Orbit est un service qui synchronise, sans aucune action de l'utilisateur, des notes en texte brut modifiées sur plusieurs appareils. Le présent document définit ses fonctions, ses interfaces externes et ses contraintes.

Ce chapitre définit ensuite le [périmètre et les hypothèses](scope.md) ainsi que les [termes](terms.md).
