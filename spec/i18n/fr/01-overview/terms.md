# 1.3 Termes

| Terme | Définition |
|---|---|
| Note | Un fichier texte, doté d'un identifiant, d'un corps, d'une heure de mise à jour et d'un numéro de version |
| Appareil | Machine sur laquelle fonctionne le client Orbit ; identifiée par un identifiant d'appareil |
| Version | Entier augmenté de un à chaque mise à jour de la note ; c'est le serveur qui l'attribue |
| Conflit | État dans lequel deux appareils ont mis à jour séparément la même version d'une note |
| Convergence | État dans lequel tous les appareils ont une note au contenu identique |
