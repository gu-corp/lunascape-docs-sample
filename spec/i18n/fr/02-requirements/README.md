# 2. Exigences

Les exigences sont identifiées par un ID, accompagné d'une priorité et d'une méthode de vérification. Les [exigences fonctionnelles](functional.md) décrivent le comportement visible par l'utilisateur ; les [exigences non fonctionnelles](non-functional.md) fixent les valeurs cibles de performance, de disponibilité et de sûreté. Chaque exigence est mise en correspondance avec les composants et les API dans le [suivi des exigences](traceability.md).
