# 4. API

Усі кінцеві точки мають основу `https://api.orbit.example/v1` і потребують `Authorization: Bearer <token>`. Тіло запиту — JSON (UTF-8).

- [Кінцеві точки](endpoints.md) — перелік і вимога, якій відповідає кожна з них
- [Запит і відповідь](push.md) — приклад тіла для `POST /notes/push`
- [Помилки](errors.md) — коди стану та дії пристрою у відповідь
