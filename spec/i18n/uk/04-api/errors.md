# 4.3 Помилки

| Стан | Значення | Дія пристрою |
|---|---|---|
| 400 | Неправильний формат запиту | Припинити надсилання та записати в журнал |
| 401 | Недійсний токен | Пройти автентифікацію повторно |
| 409 | Розбіжність версій (конфлікт) | Замінити вмістом `body` з відповіді та показати конфлікт |
| 413 | Тіло понад 1 МБ | Повідомити користувача й не надсилати |
| 429 | Забагато запитів | Зачекати кількість секунд із `Retry-After` і надіслати повторно |
| 5xx | Збій сервера | Надсилати повторно з експоненційною затримкою (до 5 разів) |
