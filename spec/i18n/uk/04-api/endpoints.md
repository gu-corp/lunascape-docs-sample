# 4.1 Кінцеві точки

| Метод | Шлях | Призначення | Вимога |
|---|---|---|---|
| POST | `/notes/push` | Надіслати зміну нотатки | REQ-001, REQ-002 |
| GET | `/notes/pull?since=<version>` | Отримати зміни після вказаної версії | REQ-001 |
| DELETE | `/notes/{id}` | Видалити нотатку (до кошика) | REQ-005 |
| POST | `/notes/{id}/restore` | Відновити нотатку з кошика | REQ-005 |
