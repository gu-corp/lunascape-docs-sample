# 2.3 Відстеження вимог

Вимоги зіставляються з елементами [архітектури](../03-architecture/README.md) та кінцевими точками [API](../04-api/README.md). Вимога без зіставлення вважається нереалізованою.

```mermaid
flowchart LR
  REQ001[REQ-001 надходить протягом 10 с] --> PUSH["/notes/push"]
  REQ002[REQ-002 надсилання після перепідключення] --> QUEUE[Черга на пристрої]
  REQ003[REQ-003 виявлення конфліктів] --> VERSION[Звірка номерів версій]
  REQ004[REQ-004 автоматичне розв'язання] --> MERGE[Тристороннє злиття]
  QUEUE --> PUSH
  VERSION --> MERGE
```
