# 2. Вимоги

Вимоги ідентифікуються за ID, до кожної додається пріоритет і спосіб перевірки. [Функціональні вимоги](functional.md) описують поведінку, видиму користувачеві; [нефункціональні вимоги](non-functional.md) задають цільові значення для продуктивності, доступності та безпеки. Кожну вимогу зіставлено з компонентами архітектури та API у розділі [Відстеження вимог](traceability.md).
