# 3.3 Номери версій

Номер версії — це монотонно зростаюче ціле число, яке сервер призначає для кожної нотатки. Пристрій надсилає останню отриману версію як `baseVersion`. Якщо поточна версія на сервері не збігається з `baseVersion`, це вважається конфліктом (REQ-003). Годинник пристрою не використовується для визначення порядку ([ORB-ADR-0001](../05-decisions/0001-sync-method.md)).
