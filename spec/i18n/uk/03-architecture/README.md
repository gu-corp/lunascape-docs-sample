# 3. Архітектура

Синхронізація складається з чотирьох елементів: клієнта, API синхронізації, сховища та сповіщень ([складники](components.md)). Порядок, у якому зміна надходить від пристрою до сервера, а від сервера — до інших пристроїв, показано в розділі [Перебіг синхронізації](sync-flow.md). Підставою для цього порядку є [номери версій](versioning.md), а те, як обробляються два оновлення однієї й тієї самої версії, визначено в розділі [Розв'язання конфліктів](conflicts.md).
