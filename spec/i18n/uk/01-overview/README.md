# 1. Загальний огляд

## 1.1 Призначення

Orbit — це служба, яка синхронізує нотатки у форматі простого тексту, що редагуються на кількох пристроях, без жодних дій з боку користувача. Цей документ визначає її функції, зовнішні інтерфейси та обмеження.

Далі в цьому розділі визначено [обсяг і передумови](scope.md) та [терміни](terms.md).
