# 1.3 Терміни

| Термін | Визначення |
|---|---|
| Нотатка | Один текстовий файл: має ідентифікатор, текст, час оновлення та номер версії |
| Пристрій | Пристрій, на якому працює клієнт Orbit; розпізнається за ідентифікатором пристрою |
| Версія | Ціле число, яке зростає на одиницю з кожним оновленням нотатки. Номер призначає сервер |
| Конфлікт | Стан, коли два пристрої окремо оновили ту саму версію нотатки |
| Збіжність | Стан, коли всі пристрої мають нотатку з однаковим вмістом |
