# 1. अवलोकन

## 1.1 उद्देश्य

Orbit एक ऐसी सेवा है जो कई उपकरणों पर संपादित की जाने वाली सादे पाठ की नोट्स को, उपयोगकर्ता की किसी क्रिया के बिना, सिंक्रनाइज़ करती है। यह दस्तावेज़ उसके कार्य, बाहरी इंटरफ़ेस और बाध्यताएँ निर्धारित करता है।

यह अध्याय आगे [कार्यक्षेत्र और पूर्वधारणाएँ](scope.md) तथा [शब्दावली](terms.md) निर्धारित करता है।
