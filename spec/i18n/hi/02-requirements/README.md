# 2. आवश्यकताएँ

आवश्यकताओं की पहचान ID से होती है, और उनके साथ प्राथमिकता तथा सत्यापन की विधि दी जाती है। [कार्यात्मक आवश्यकताएँ](functional.md) उपयोगकर्ता को दिखने वाले व्यवहार का वर्णन करती हैं; [गैर-कार्यात्मक आवश्यकताएँ](non-functional.md) निष्पादन, उपलब्धता और सुरक्षा के लक्ष्य मान तय करती हैं। प्रत्येक आवश्यकता को [आवश्यकताओं की ट्रेसेबिलिटी](traceability.md) के माध्यम से संरचना के घटकों और API से जोड़ा जाता है।
