# 4. API

- [अनुरोध और प्रतिक्रिया](push.md) — `POST /notes/push` के मुख्य भाग का उदाहरण
- [त्रुटियाँ](errors.md) — स्थिति कोड और डिवाइस की प्रतिक्रिया
