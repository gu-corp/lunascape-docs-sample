# 4.3 त्रुटियाँ

| स्थिति | अर्थ | डिवाइस क्या करे |
|---|---|---|
| 400 | अनुरोध का प्रारूप गलत है | भेजना बंद करें और लॉग में दर्ज करें |
| 401 | टोकन अमान्य है | पुनः प्रमाणीकरण करें |
| 409 | संस्करण मेल नहीं खाता (टकराव) | प्रतिक्रिया के `body` से बदलें और टकराव दिखाएँ |
| 413 | मुख्य भाग 1 MB से बड़ा है | उपयोगकर्ता को बताएँ और न भेजें |
| 429 | अनुरोध बहुत अधिक हैं | `Retry-After` में बताए सेकंड तक प्रतीक्षा करें, फिर पुनः भेजें |
| 5xx | सर्वर की विफलता | एक्सपोनेंशियल बैकऑफ़ के साथ पुनः भेजें (अधिकतम 5 बार) |
