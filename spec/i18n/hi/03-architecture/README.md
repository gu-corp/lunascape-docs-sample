# 3. संरचना

सिंक चार तत्वों से बनता है: क्लाइंट, सिंक API, स्टोर और सूचनाएँ ([घटक](components.md))। किसी उपकरण से सर्वर तक, और सर्वर से अन्य उपकरणों तक परिवर्तन किस क्रम में पहुँचता है, यह [सिंक का प्रवाह](sync-flow.md) में दिखाया गया है। उस क्रम का आधार [संस्करण संख्याएँ](versioning.md) हैं; एक ही संस्करण पर दो अद्यतन आ जाने पर उनका निपटारा [विरोध का समाधान](conflicts.md) में निर्धारित है।
