# 4. API

Všechny koncové body vycházejí z `https://api.orbit.example/v1` a vyžadují `Authorization: Bearer <token>`. Těla zpráv jsou ve formátu JSON (UTF-8).

- [Koncové body](endpoints.md) — seznam a odpovídající požadavky
- [Požadavek a odpověď](push.md) — ukázka těla pro `POST /notes/push`
- [Chyby](errors.md) — stavové kódy a reakce zařízení
