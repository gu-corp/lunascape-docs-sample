# 2. Požadavky

Požadavky se identifikují pomocí ID a doplňují se o prioritu a způsob ověření. [Funkční požadavky](functional.md) popisují chování viditelné pro uživatele, [nefunkční požadavky](non-functional.md) stanovují cílové hodnoty výkonu, dostupnosti a bezpečnosti. Každý požadavek je pomocí [sledovatelnosti požadavků](traceability.md) přiřazen ke stavebním prvkům a rozhraním API.
