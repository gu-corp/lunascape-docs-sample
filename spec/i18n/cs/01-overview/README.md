# 1. Přehled

## 1.1 Účel

Orbit je služba, která synchronizuje poznámky v prostém textu upravované na více zařízeních, aniž by uživatel musel cokoli udělat. Tento dokument vymezuje její funkce, vnější rozhraní a omezení.

Tato kapitola dále vymezuje [rozsah a předpoklady](scope.md) a [pojmy](terms.md).
