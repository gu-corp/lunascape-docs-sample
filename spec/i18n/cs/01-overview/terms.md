# 1.3 Pojmy

| Pojem | Definice |
|---|---|
| Poznámka | Jeden textový soubor s identifikátorem, obsahem, časem aktualizace a číslem verze |
| Zařízení | Stroj, na kterém běží klient Orbit; identifikuje se pomocí ID zařízení |
| Verze | Celé číslo, které se s každou aktualizací poznámky zvýší o jedna; přiděluje je server |
| Konflikt | Stav, kdy dvě zařízení nezávisle na sobě aktualizovala stejnou verzi poznámky |
| Konvergence | Stav, kdy všechna zařízení mají stejný obsah poznámky |
