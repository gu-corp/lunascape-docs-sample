# 1.2 Rozsah a předpoklady

## Rozsah

| Č. | Patří do rozsahu | Nepatří do rozsahu |
|---|---|---|
| 1 | Synchronizace vytvoření, úpravy a smazání poznámky | Společné úpravy poznámky (sdílení kurzoru při současné úpravě) |
| 2 | Zjišťování a řešení konfliktů mezi zařízeními | Editor v zařízení |
| 3 | Synchronizační API (HTTP) | Účtování, správa účtů |

## Předpoklady

- Zařízení se připojují jen občas. Předpokládá se úprava offline.
- Text poznámky má horní hranici 1 MB.
- Pořadí nezávisí na hodinách zařízení; určují je čísla verzí ze serveru.
