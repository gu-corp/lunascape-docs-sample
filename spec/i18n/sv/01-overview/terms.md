# 1.3 Termer

| Term | Definition |
|---|---|
| Anteckning | En textfil med ett id, en brödtext, en uppdateringstid och ett versionsnummer |
| Enhet | En maskin som kör Orbit-klienten, identifierad med ett enhets-id |
| Version | Ett heltal som ökar med ett vid varje uppdatering; servern tilldelar det |
| Konflikt | Två enheter har uppdaterat samma version av en anteckning var för sig |
| Konvergens | Alla enheter har samma innehåll i en anteckning |
