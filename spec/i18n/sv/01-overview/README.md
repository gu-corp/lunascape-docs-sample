# 1. Översikt

## 1.1 Syfte

Orbit är en tjänst som synkroniserar anteckningar i vanlig text, redigerade på flera enheter, utan någon åtgärd från användaren. Detta dokument fastställer dess funktioner, externa gränssnitt och begränsningar.

Detta kapitel fastställer därefter [omfattning och förutsättningar](scope.md) samt [termer](terms.md).
