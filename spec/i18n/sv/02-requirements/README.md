# 2. Krav

Krav identifieras med ID och förses med prioritet och verifieringsmetod. [Funktionella krav](functional.md) beskriver beteende som är synligt för användaren, medan [icke-funktionella krav](non-functional.md) anger målvärden för prestanda, tillgänglighet och säkerhet. Varje krav kopplas till komponenter och API:er genom [kravspårning](traceability.md).
