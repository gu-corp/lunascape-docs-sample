# 1. Oversigt

## 1.1 Formål

Orbit synkroniserer almindelige tekstnoter, der redigeres på flere enheder, uden at brugeren foretager sig noget. Denne specifikation fastlægger tjenestens funktioner, eksterne grænseflader og begrænsninger.

Kapitlet fastlægger derefter [omfang og forudsætninger](scope.md) samt [termer](terms.md).
