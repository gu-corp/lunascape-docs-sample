# 2. Krav

Krav identificeres med et ID og forsynes med en prioritet og en verifikationsmetode. [Funktionelle krav](functional.md) beskriver den adfærd, brugeren kan se; [ikke-funktionelle krav](non-functional.md) fastsætter målværdier for ydelse, tilgængelighed og sikkerhed. Hvert krav knyttes til komponenter og API'er i [sporbarhed for krav](traceability.md).
