# 4. API

Все конечные точки строятся от `https://api.orbit.example/v1` и требуют заголовка `Authorization: Bearer <token>`. Тело запроса — JSON (UTF-8).

- [Запрос и ответ](push.md) — пример тела `POST /notes/push`
