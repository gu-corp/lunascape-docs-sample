# 4.1 Конечные точки

| Метод | Путь | Назначение | Требование |
|---|---|---|---|
| POST | `/notes/push` | Отправить изменение заметки | REQ-001, REQ-002 |
| GET | `/notes/pull?since=<version>` | Получить изменения после указанной версии | REQ-001 |
| DELETE | `/notes/{id}` | Удалить заметку (в корзину) | REQ-005 |
| POST | `/notes/{id}/restore` | Восстановить заметку из корзины | REQ-005 |
