# 4.3 Ошибки

|状態 | 意味 | 端末の対処 |
|---|---|---|
| 400 | Неверный формат запроса | Прекратить отправку и записать в журнал |
| 401 | Недействительный токен | Пройти повторную аутентификацию |
| 409 | Несовпадение версий (конфликт) | Заменить содержимым `body` из ответа и показать конфликт |
| 413 | Тело превышает 1 МБ | Сообщить пользователю и не отправлять |
| 429 | Слишком много запросов | Подождать число секунд, указанное в `Retry-After`, и отправить повторно |
| 5xx | Сбой сервера | Повторять отправку с экспоненциальной задержкой (не более 5 раз) |
