# 2. Требования

Требования идентифицируются по ID, к каждому прилагаются приоритет и способ проверки. [Функциональные требования](functional.md) описывают поведение, видимое пользователю; [нефункциональные требования](non-functional.md) задают целевые значения производительности, доступности и безопасности. Каждое требование сопоставляется с компонентами и API через [трассируемость требований](traceability.md).
