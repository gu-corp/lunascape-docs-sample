# 2.3 Трассируемость требований

Требования сопоставляются с элементами [архитектуры](../03-architecture/README.md) и с конечными точками [API](../04-api/README.md). Требование без сопоставления считается нереализованным.

```mermaid
flowchart LR
  REQ001[REQ-001 доставка в пределах 10 с] --> PUSH["/notes/push"]
  REQ002[REQ-002 отправка при переподключении] --> QUEUE[Очередь на устройстве]
  REQ003[REQ-003 обнаружение конфликтов] --> VERSION[Сверка номеров версий]
  REQ004[REQ-004 автоматическое разрешение] --> MERGE[Трехстороннее слияние]
  QUEUE --> PUSH
  VERSION --> MERGE
```
