# 2.1 Функциональные требования

| ID | Требование | Приоритет | Способ проверки |
|---|---|---|---|
| REQ-001 | Заметка, созданная на одном устройстве, доходит до других устройств в течение 10 секунд после подключения | Обязательно | Интеграционный тест |
| REQ-002 | Заметка, отредактированная офлайн, отправляется автоматически при восстановлении соединения | Обязательно | Интеграционный тест |
| REQ-003 | Два обновления одной и той же версии обнаруживаются как конфликт | Обязательно | Модульный тест |
| REQ-004 | Конфликт разрешается автоматически по [правилам из 3.4](../03-architecture/conflicts.md), без потери содержимого ни одной из сторон | Обязательно | Модульный тест |
| REQ-005 | Удаление распространяется на другие устройства, а восстановить запись из корзины можно в течение 30 дней | Рекомендуется | Интеграционный тест |
| REQ-006 | Устройство может показывать состояние синхронизации (синхронизировано, отправка, есть конфликт) | Рекомендуется | Визуальная проверка |
