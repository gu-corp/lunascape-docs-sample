# 2.2 Нефункциональные требования

| ID | Требование | Целевое значение |
|---|---|---|
| NFR-001 | Время отклика API синхронизации | Не более 300 мс для 95-го процентиля |
| NFR-002 | Доступность | 99,9 % в месяц |
| NFR-003 | Защита передачи данных | TLS 1.3. Текст заметок шифруется при хранении на сервере |
| NFR-004 | Количество заметок на одного пользователя | Требования к производительности выполняются до 100 000 заметок |
