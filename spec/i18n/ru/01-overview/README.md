# 1. Обзор

## 1.1 Назначение

Orbit — это служба, которая синхронизирует заметки в виде обычного текста, редактируемые на нескольких устройствах, без каких-либо действий со стороны пользователя. Настоящая спецификация определяет ее функции, внешние интерфейсы и ограничения.

Далее в этой главе определяются [область применения и допущения](scope.md), а также [термины](terms.md).
