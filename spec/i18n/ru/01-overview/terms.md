# 1.3 Термины

| Термин | Определение |
|---|---|
| Заметка | Один текстовый файл. Имеет идентификатор, текст, время обновления и номер версии |
| Устройство | Устройство, на котором работает клиент Orbit. Определяется по идентификатору устройства |
| Версия | Целое число, увеличивающееся на единицу при каждом обновлении заметки. Присваивается сервером |
| Конфликт | Состояние, при котором два устройства независимо обновили одну и ту же версию заметки |
| Сходимость | Состояние, при котором все устройства содержат одинаковое содержимое заметки |
