# 3.3 Номера версий

Номер версии — это монотонно возрастающее целое число, которое сервер присваивает каждой заметке. Устройство отправляет последнюю полученную версию как `baseVersion`. Если текущая версия на сервере не совпадает с `baseVersion`, возникает конфликт (REQ-003). Часы устройства не участвуют в определении порядка ([ORB-ADR-0001](../05-decisions/0001-sync-method.md)).
