# 3.4 Разрешение конфликтов

| Случай | Правило |
|---|---|
| Одна и та же строка изменена независимо | Сохраняются оба изменения: то, которое пришло позже, добавляется в конец и отделяется знаком `>>>`. Пользователю показывается наличие конфликта (REQ-006) |
| Изменены разные строки | Объединяются автоматически трехсторонним слиянием; пользователю об этом не сообщается |
| Одна из сторон удалила запись | Удаление имеет приоритет, а содержимое другой стороны помещается в корзину (REQ-005) |

Во всех случаях содержимое не теряется (REQ-004).
