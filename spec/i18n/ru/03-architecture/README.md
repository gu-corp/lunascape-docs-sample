# 3. Архитектура

Синхронизация складывается из четырёх элементов: клиента, API синхронизации, хранилища и уведомлений ([составные части](components.md)). Порядок, в котором изменение доходит от устройства до сервера и от сервера до других устройств, показан в разделе [Поток синхронизации](sync-flow.md). Основанием этого порядка служат [номера версий](versioning.md), а правила на случай, когда два обновления приходят к одной и той же версии, определены в разделе [Разрешение конфликтов](conflicts.md).
