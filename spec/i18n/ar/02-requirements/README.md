# ٢. المتطلبات

تُعرَّف المتطلبات بمعرّف، ويُرفق بكل منها أولوية وطريقة تحقّق. تصف [المتطلبات الوظيفية](functional.md) السلوك الظاهر للمستخدم، بينما تحدّد [المتطلبات غير الوظيفية](non-functional.md) القيم المستهدفة للأداء والإتاحة والأمان. ويُربط كل متطلب بعناصر البنية وواجهات API من خلال [تتبّع المتطلبات](traceability.md).
