# ٣.٤ حل التعارضات

| الحالة | القاعدة |
|---|---|
| تغيّر السطر نفسه بصورة مستقلة | يُحتفظ بكلا التغييرين: يُلحق التغيير الذي وصل لاحقًا في النهاية مفصولًا بعلامة `>>>`. ويُعرض للمستخدم وجود تعارض (REQ-006) |
| تغيّرت أسطر مختلفة | تُدمج تلقائيًا بدمج ثلاثي الاتجاهات، ولا يُبلَّغ المستخدم بذلك |
| حذف أحد الطرفين المحتوى | تُقدَّم عملية الحذف، وينتقل محتوى الطرف الآخر إلى سلة المحذوفات (REQ-005) |

وفي جميع الحالات لا يُفقد أي محتوى (REQ-004).
