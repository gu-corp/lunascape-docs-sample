# 1.3 المصطلحات

| المصطلح | التعريف |
|---|---|
| ملاحظة | ملف نصي واحد، له معرّف ومتن ووقت تحديث ورقم إصدار |
| جهاز | جهاز يعمل عليه عميل Orbit، ويُعرَّف بمعرّف الجهاز |
| إصدار | عدد صحيح يزداد بمقدار واحد مع كل تحديث للملاحظة؛ يمنحه الخادم |
| تعارض | حالة يحدّث فيها جهازان الإصدار نفسه من الملاحظة كلٌّ على حدة |
| تقارب | حالة تمتلك فيها جميع الأجهزة المحتوى نفسه للملاحظة |
