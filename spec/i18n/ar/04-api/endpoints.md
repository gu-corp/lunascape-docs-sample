# 4.1 نقاط النهاية

| الطريقة | المسار | الغرض | المتطلب |
|---|---|---|---|
| POST | `/notes/push` | إرسال تغيير في ملاحظة | REQ-001، REQ-002 |
| GET | `/notes/pull?since=<version>` | استقبال التغييرات اللاحقة للإصدار المحدد | REQ-001 |
| DELETE | `/notes/{id}` | حذف ملاحظة (إلى سلة المحذوفات) | REQ-005 |
| POST | `/notes/{id}/restore` | استعادة ملاحظة من سلة المحذوفات | REQ-005 |
