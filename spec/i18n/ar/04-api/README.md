# 4. واجهة برمجة التطبيقات (API)

تنطلق جميع نقاط النهاية من `https://api.orbit.example/v1`، وتتطلّب `Authorization: Bearer <token>`. ويكون المحتوى بصيغة JSON (UTF-8).

- [نقاط النهاية](endpoints.md) — القائمة، والمتطلّب المقابل لكلٍّ منها
- [الطلب والاستجابة](push.md) — مثال على محتوى `POST /notes/push`
- [الأخطاء](errors.md) — رموز الحالة وما يفعله الجهاز حيالها
