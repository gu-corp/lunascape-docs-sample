# 2. ข้อกำหนดความต้องการ

ความต้องการแต่ละข้อระบุด้วย ID พร้อมแนบลำดับความสำคัญและวิธีตรวจสอบ [ความต้องการเชิงหน้าที่](functional.md) คือพฤติกรรมที่ผู้ใช้มองเห็น ส่วน [ความต้องการที่ไม่ใช่เชิงหน้าที่](non-functional.md) คือค่าเป้าหมายด้านสมรรถนะ ความพร้อมใช้งาน และความปลอดภัย ความต้องการแต่ละข้อจะถูกจับคู่กับองค์ประกอบของสถาปัตยกรรมและ API ผ่าน [การติดตามความต้องการ](traceability.md)
