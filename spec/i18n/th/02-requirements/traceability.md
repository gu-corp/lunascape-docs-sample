# 2.3 การติดตามข้อกำหนด

ข้อกำหนดแต่ละข้อจะเชื่อมโยงกับองค์ประกอบต่าง ๆ ใน[โครงสร้าง](../03-architecture/README.md) และกับปลายทางแต่ละรายการของ [API](../04-api/README.md) ข้อกำหนดที่ไม่มีการเชื่อมโยงจะถือว่ายังไม่ได้พัฒนา

```mermaid
flowchart LR
  REQ001[REQ-001 ส่งถึงภายใน 10 วินาที] --> PUSH["/notes/push"]
  REQ002[REQ-002 ส่งเมื่อเชื่อมต่อใหม่] --> QUEUE[คิวฝั่งอุปกรณ์]
  REQ003[REQ-003 การตรวจจับความขัดแย้ง] --> VERSION[การตรวจสอบหมายเลขเวอร์ชัน]
  REQ004[REQ-004 การแก้ไขอัตโนมัติ] --> MERGE[การผสานสามทาง]
  QUEUE --> PUSH
  VERSION --> MERGE
```
