# 2.2 ข้อกำหนดที่ไม่ใช่เชิงหน้าที่

| ID | ข้อกำหนด | ค่าเป้าหมาย |
|---|---|---|
| NFR-001 | เวลาตอบสนองของ API การซิงค์ | ไม่เกิน 300 มิลลิวินาที ที่เปอร์เซ็นไทล์ที่ 95 |
| NFR-002 | ความพร้อมใช้งาน | 99.9 % ต่อเดือน |
