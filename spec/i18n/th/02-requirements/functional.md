# 2.1 ข้อกำหนดด้านฟังก์ชัน

| ID | ข้อกำหนด | ลำดับความสำคัญ | วิธีตรวจสอบ |
|---|---|---|---|
| REQ-001 | บันทึกที่สร้างบนอุปกรณ์หนึ่งไปถึงอุปกรณ์อื่นภายใน 10 วินาทีหลังเชื่อมต่อ | จำเป็น | การทดสอบแบบรวม |
| REQ-002 | บันทึกที่แก้ไขขณะออฟไลน์จะถูกส่งโดยอัตโนมัติเมื่อเชื่อมต่อใหม่ | จำเป็น | การทดสอบแบบรวม |
| REQ-003 | การอัปเดตสองรายการต่อรุ่นเดียวกันจะถูกตรวจพบว่าขัดแย้งกัน | จำเป็น | การทดสอบหน่วย |
| REQ-004 | ความขัดแย้งจะได้รับการแก้ไขโดยอัตโนมัติตาม [กฎในข้อ 3.4](../03-architecture/conflicts.md) โดยไม่สูญเสียเนื้อหาของทั้งสองฝ่าย | จำเป็น | การทดสอบหน่วย |
| REQ-005 | การลบจะสะท้อนไปยังอุปกรณ์อื่นด้วย และกู้คืนจากถังขยะได้ภายใน 30 วัน | แนะนำ | การทดสอบแบบรวม |
| REQ-006 | อุปกรณ์แสดงสถานะการซิงค์ได้ (ซิงค์แล้ว กำลังส่ง มีความขัดแย้ง) | แนะนำ | การตรวจด้วยสายตา |
