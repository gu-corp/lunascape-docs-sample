# 4.1 ปลายทาง

| เมธอด | พาธ | วัตถุประสงค์ | ข้อกำหนด |
|---|---|---|---|
| POST | `/notes/push` | ส่งการเปลี่ยนแปลงของโน้ต | REQ-001, REQ-002 |
| GET | `/notes/pull?since=<version>` | รับการเปลี่ยนแปลงหลังจากเวอร์ชันที่ระบุ | REQ-001 |
| DELETE | `/notes/{id}` | ลบโน้ต (ย้ายไปถังขยะ) | REQ-005 |
| POST | `/notes/{id}/restore` | กู้คืนจากถังขยะ | REQ-005 |
