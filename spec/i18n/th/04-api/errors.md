# 4.3 ข้อผิดพลาด

| สถานะ | ความหมาย | สิ่งที่อุปกรณ์ต้องทำ |
|---|---|---|
| 400 | รูปแบบของคำขอไม่ถูกต้อง | หยุดส่ง และบันทึกลงล็อก |
| 401 | โทเค็นไม่ถูกต้อง | ยืนยันตัวตนใหม่ |
| 409 | เวอร์ชันไม่ตรงกัน (ขัดแย้ง) | แทนที่ด้วย `body` ของการตอบกลับ และแสดงว่ามีความขัดแย้ง |
| 413 | เนื้อหาเกิน 1 MB | แจ้งผู้ใช้ และไม่ส่ง |
| 429 | คำขอมากเกินไป | รอตามจำนวนวินาทีที่ระบุใน `Retry-After` แล้วส่งใหม่ |
| 5xx | เซิร์ฟเวอร์ขัดข้อง | ส่งใหม่แบบ exponential backoff (ไม่เกิน 5 ครั้ง) |
