# 4. API

ทุกเอนด์พอยต์มีจุดตั้งต้นที่ `https://api.orbit.example/v1` และต้องมี `Authorization: Bearer <token>` เนื้อความเป็น JSON (UTF-8)

- [เอนด์พอยต์](endpoints.md) — รายการทั้งหมด และข้อกำหนดที่รองรับ
- [คำขอและการตอบกลับ](push.md) — ตัวอย่างเนื้อความของ `POST /notes/push`
- [ข้อผิดพลาด](errors.md) — รหัสสถานะ และการรับมือของอุปกรณ์
