# 1. ภาพรวม

## 1.1 วัตถุประสงค์

Orbit เป็นบริการที่ซิงค์โน้ตข้อความธรรมดาซึ่งแก้ไขบนอุปกรณ์หลายเครื่อง โดยผู้ใช้ไม่ต้องดำเนินการใด ๆ เอกสารฉบับนี้กำหนดฟังก์ชัน อินเทอร์เฟซภายนอก และข้อจำกัดของบริการดังกล่าว

บทนี้กำหนด[ขอบเขตและข้อสมมติ](scope.md) และ[คำศัพท์](terms.md) ต่อไป
