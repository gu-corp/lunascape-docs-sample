# 1.3 คำศัพท์

| คำศัพท์ | ความหมาย |
|---|---|
| โน้ต | ไฟล์ข้อความหนึ่งไฟล์ มีตัวระบุ เนื้อหา เวลาที่อัปเดต และหมายเลขเวอร์ชัน |
| อุปกรณ์ | เครื่องที่ใช้งานไคลเอ็นต์ Orbit ระบุด้วยรหัสอุปกรณ์ |
| เวอร์ชัน | จำนวนเต็มที่เพิ่มขึ้นครั้งละ 1 ทุกครั้งที่อัปเดตโน้ต เซิร์ฟเวอร์เป็นผู้กำหนดหมายเลข |
| ความขัดแย้ง | สถานะที่อุปกรณ์สองเครื่องอัปเดตโน้ตเวอร์ชันเดียวกันแยกจากกัน |
| การบรรจบ | สถานะที่อุปกรณ์ทุกเครื่องมีเนื้อหาของโน้ตตรงกัน |
