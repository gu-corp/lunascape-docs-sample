# 1.2 ขอบเขตและข้อสมมติ

## ขอบเขต

| ลำดับ | อยู่ในขอบเขต | ไม่อยู่ในขอบเขต |
|---|---|---|
| 1 | การซิงค์การสร้าง การอัปเดต และการลบโน้ต | การแก้ไขโน้ตร่วมกัน (การใช้เคอร์เซอร์ร่วมกันขณะแก้ไขพร้อมกัน) |
| 2 | การตรวจจับและแก้ไขความขัดแย้งระหว่างอุปกรณ์ | เอดิเตอร์ภายในอุปกรณ์ |
| 3 | API การซิงค์ (HTTP) | การเรียกเก็บเงิน การจัดการบัญชี |

## ข้อสมมติ

- อุปกรณ์เชื่อมต่อเป็นช่วง ๆ เท่านั้น โดยถือว่าการแก้ไขแบบออฟไลน์เป็นเรื่องปกติ
- เนื้อหาของโน้ตมีขนาดไม่เกิน 1 MB
- ลำดับไม่ขึ้นกับนาฬิกาของอุปกรณ์ แต่กำหนดด้วยหมายเลขเวอร์ชันของเซิร์ฟเวอร์
