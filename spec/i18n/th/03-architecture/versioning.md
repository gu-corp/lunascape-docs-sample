# 3.3 หมายเลขเวอร์ชัน

หมายเลขเวอร์ชันคือจำนวนเต็มที่เพิ่มขึ้นแบบทางเดียว ซึ่งเซิร์ฟเวอร์กำหนดให้แยกตามโน้ตแต่ละรายการ อุปกรณ์จะส่งเวอร์ชันล่าสุดที่ได้รับมาเป็น `baseVersion` เมื่อเวอร์ชันปัจจุบันของเซิร์ฟเวอร์ไม่ตรงกับ `baseVersion` ถือว่าเกิดความขัดแย้ง (REQ-003) นาฬิกาของอุปกรณ์ไม่ถูกนำมาใช้ในการกำหนดลำดับ ([ORB-ADR-0001](../05-decisions/0001-sync-method.md))
