# 3. โครงสร้าง

การซิงค์ประกอบด้วยองค์ประกอบ 4 อย่าง ได้แก่ ไคลเอ็นต์ API การซิงค์ ที่เก็บข้อมูล และการแจ้งเตือน ([องค์ประกอบ](components.md)) ลำดับที่การเปลี่ยนแปลงเดินทางจากอุปกรณ์ไปยังเซิร์ฟเวอร์ และจากเซิร์ฟเวอร์ไปยังอุปกรณ์อื่น แสดงไว้ใน [ลำดับการซิงค์](sync-flow.md) ลำดับดังกล่าวตั้งอยู่บน [หมายเลขเวอร์ชัน](versioning.md) และการจัดการเมื่อมีการอัปเดตซ้อนกันบนเวอร์ชันเดียวกัน กำหนดไว้ใน [การแก้ปัญหาความขัดแย้ง](conflicts.md)
