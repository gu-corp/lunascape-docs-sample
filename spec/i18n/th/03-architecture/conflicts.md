# 3.4 การแก้ไขข้อขัดแย้ง

| กรณี | กฎ |
|---|---|
| แก้ไขบรรทัดเดียวกันแยกจากกัน | เก็บการเปลี่ยนแปลงไว้ทั้งสองฝ่าย โดยนำฝ่ายที่มาถึงทีหลังไปต่อท้าย คั่นด้วย `>>>` และแสดงแก่ผู้ใช้ว่ามีข้อขัดแย้ง (REQ-006) |
| แก้ไขคนละบรรทัด | รวมเข้าด้วยกันโดยอัตโนมัติด้วยการผสานสามทาง ไม่แจ้งให้ผู้ใช้ทราบ |
| ฝ่ายหนึ่งลบ | ให้การลบมีผลก่อน และนำเนื้อหาของอีกฝ่ายไปไว้ในถังขยะ (REQ-005) |

ไม่ว่ากรณีใด เนื้อหาจะไม่สูญหาย (REQ-004)
