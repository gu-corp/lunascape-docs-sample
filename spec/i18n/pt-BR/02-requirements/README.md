# 2. Requisitos

Os requisitos são identificados por ID, acompanhados de uma prioridade e de um método de verificação. Os [requisitos funcionais](functional.md) descrevem o comportamento visível ao usuário; os [requisitos não funcionais](non-functional.md) definem as metas de desempenho, disponibilidade e segurança. Cada requisito é associado aos componentes e às APIs em [rastreabilidade dos requisitos](traceability.md).
