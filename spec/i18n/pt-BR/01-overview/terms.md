# 1.3 Termos

| Termo | Definição |
|---|---|
| Nota | Um arquivo de texto, com identificador, corpo, horário de atualização e número de versão |
| Dispositivo | A máquina em que o cliente Orbit é executado; identificada por um ID de dispositivo |
| Versão | Número inteiro que aumenta em 1 a cada atualização da nota; atribuído pelo servidor |
| Conflito | Estado em que dois dispositivos atualizaram separadamente a mesma versão de uma nota |
| Convergência | Estado em que todos os dispositivos têm a nota com o mesmo conteúdo |
