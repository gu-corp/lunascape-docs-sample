# 1. Visão geral

## 1.1 Objetivo

O Orbit sincroniza notas em texto simples editadas em vários dispositivos, sem nenhuma ação do usuário. Esta especificação define suas funções, interfaces externas e restrições.

Este capítulo define, na sequência, o [escopo e as premissas](scope.md) e os [termos](terms.md).
