# ORB-ADR-0001: 同期方式を「サーバー採番の版と 3 方向マージ」とする

| 項目 | 内容 |
|---|---|
| 文書ID | ORB-ADR-0001 |
| 版 | 1.0 |
| 更新日 | 2026-07-01 |
| 状態 | 承認済み |

## 1. 背景

オフラインで編集される複数端末のノートを収束させる必要がある。候補は、(a) 最終更新時刻の勝ち、(b) CRDT、(c) サーバー採番の版番号と 3 方向マージ、の 3 つであった。

## 2. 決定

| 項番 | 決定事項 |
|---|---|
| 1 | 順序はサーバーが採番する版番号で決める。端末の時計を信用しない |
| 2 | 競合は 3 方向マージで解決し、解決できない行は両方を残す。内容を失わないことを優先する |
| 3 | CRDT は採用しない。ノートは短く、同時編集の要求がなく、本文のサイズが 2 倍以上になる代償に見合わないため |

## 3. 影響

| 項番 | 影響 |
|---|---|
| 1 | 端末は `baseVersion` を保持し、送信のたびに添える |
| 2 | 競合の表示（REQ-006）が端末の必須機能になる |
| 3 | サーバーは直近 30 日の履歴を持つ（ごみ箱と 3 方向マージの基底のため） |
