# 1. 概要

## 1.1 目的

Orbit は、複数の端末で編集されるプレーンテキストのノートを、利用者の操作なしに同期するサービスである。本書は、その機能、外部インターフェースおよび制約を定める。

## 1.2 範囲

| 項番 | 範囲に含む | 範囲に含まない |
|---|---|---|
| 1 | ノートの作成、更新、削除の同期 | ノートの共同編集（同時編集のカーソル共有） |
| 2 | 端末間の競合の検出と解決 | 端末内のエディター |
| 3 | 同期 API（HTTP） | 課金、アカウントの管理 |

## 1.3 用語

| 用語 | 定義 |
|---|---|
| ノート | 1 つのテキストファイル。識別子、本文、更新時刻、版番号を持つ |
| 端末 | Orbit クライアントが動作する機器。端末 ID で識別する |
| 版 | ノートの更新ごとに 1 ずつ増える整数。サーバーが採番する |
| 競合 | 2 つの端末が同じ版のノートを別々に更新した状態 |
| 収束 | すべての端末が同じ内容のノートを持つ状態 |

## 1.4 前提

- 端末は間欠的にしか接続しない。オフラインでの編集を前提とする。
- ノートの本文は 1 MB を上限とする。
- 時刻は端末の時計に依存せず、サーバーの版番号で順序を決める。
