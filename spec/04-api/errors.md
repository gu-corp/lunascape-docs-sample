# 4.3 エラー

| 状態 | 意味 | 端末の対処 |
|---|---|---|
| 400 | 要求の形式が不正 | 送信をやめ、ログに残す |
| 401 | トークンが無効 | 再認証する |
| 409 | 版の不一致（競合） | 応答の `body` で置き換え、競合ありと表示する |
| 413 | 本文が 1 MB を超える | 利用者に知らせ、送信しない |
| 429 | 要求が多すぎる | `Retry-After` の秒数だけ待って再送する |
| 5xx | サーバーの障害 | 指数バックオフで再送する（最大 5 回） |
