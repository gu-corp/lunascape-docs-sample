# 有限グラフ上のランダムウォークの混合時間について

**著者**: 架空 太郎（Orbit 研究所）、Jane Example（Example University）
**日付**: 2026-09-06 ・ **分類**: 確率論、グラフ理論

## 要旨

有限連結グラフ上の遅延ランダムウォークについて、混合時間 \(t_{\mathrm{mix}}(\varepsilon)\) がスペクトルギャップ \(\gamma\) と定常分布の最小値 \(\pi_{\min}\) で上から抑えられることを整理し、円グラフと完全グラフで評価の精度を比べる。本稿は Lunascape Docs で論文を書く例として、定理と証明、Mermaid による図、Vega-Lite によるグラフ、参考文献の書き方を示す。

**キーワード**: ランダムウォーク、混合時間、スペクトルギャップ、マルコフ連鎖
