# Satunnaiskulkujen sekoittumisajoista äärellisillä graafeilla

**Tekijät**: Taro Kakū (Orbit-tutkimuslaitos), Jane Example (Example University)
**Päiväys**: 2026-09-06 · **Luokitus**: todennäköisyysteoria, graafiteoria

## Tiivistelmä

Äärellisen yhtenäisen graafin laiskalle satunnaiskululle kootaan yläraja sekoittumisajalle \(t_{\mathrm{mix}}(\varepsilon)\) spektrivälin \(\gamma\) ja stationaarisen jakauman minimin \(\pi_{\min}\) avulla, ja arvion tarkkuutta verrataan syklisillä graafeilla ja täydellisillä graafeilla. Kirjoitus toimii samalla esimerkkinä artikkelin kirjoittamisesta Lunascape Docsissa: lauseet ja todistukset, Mermaid-kaavio, Vega-Lite-kuvaaja ja lähdeviitteet.

**Avainsanat**: satunnaiskulku, sekoittumisaika, spektriväli, Markovin ketju
