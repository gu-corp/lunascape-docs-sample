# Om blandningstider för slumpvandringar på ändliga grafer

**Författare**: Taro Kakū (Orbit Research), Jane Example (Example University)
**Datum**: 2026-09-06 · **Ämnen**: sannolikhetsteori, grafteori

## Sammanfattning

För den lata slumpvandringen på en ändlig sammanhängande graf går vi igenom hur blandningstiden \(t_{\mathrm{mix}}(\varepsilon)\) kan begränsas uppåt med hjälp av spektralgapet \(\gamma\) och det minsta värdet i den stationära fördelningen \(\pi_{\min}\), och jämför uppskattningens skärpa för cykelgrafer och fullständiga grafer. Artikeln fungerar samtidigt som ett exempel på att skriva en artikel i Lunascape Docs: satser och bevis, ett diagram med Mermaid, ett diagram med Vega-Lite och referenser.

**Nyckelord**: slumpvandring, blandningstid, spektralgap, Markovkedja
