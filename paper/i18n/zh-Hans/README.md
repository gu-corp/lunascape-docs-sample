# 有限图上随机游走的混合时间

**作者**：架空太郎（Orbit 研究所）、Jane Example（Example University）
**日期**：2026-09-06 · **分类**：概率论、图论

## 摘要

针对有限连通图上的懒惰随机游走，本文整理了混合时间 \(t_{\mathrm{mix}}(\varepsilon)\) 由谱隙 \(\gamma\) 与平稳分布最小值 \(\pi_{\min}\) 给出的上界，并在圈图与完全图上比较该估计的精度。本文同时作为用 Lunascape Docs 撰写论文的示例，展示定理与证明、Mermaid 图表、Vega-Lite 图表以及参考文献的写法。

**关键词**：随机游走、混合时间、谱隙、马尔可夫链
