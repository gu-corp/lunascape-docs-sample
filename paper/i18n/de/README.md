# Über Mischzeiten von Irrfahrten auf endlichen Graphen

**Autoren**: Taro Kakū (Orbit Research), Jane Example (Example University)
**Datum**: 2026-09-06 · **Fachgebiete**: Wahrscheinlichkeitstheorie, Graphentheorie

## Zusammenfassung

Für die träge Irrfahrt auf einem endlichen zusammenhängenden Graphen stellen wir die Abschätzung der Mischzeit \(t_{\mathrm{mix}}(\varepsilon)\) durch die Spektrallücke \(\gamma\) und das Minimum der stationären Verteilung \(\pi_{\min}\) zusammen und vergleichen ihre Genauigkeit an Kreisgraphen und vollständigen Graphen.
