# O časech promíchání náhodných procházek na konečných grafech

**Autoři**: Taro Kakú (Orbit Research), Jane Example (Example University)
**Datum**: 2026-09-06 · **Obory**: teorie pravděpodobnosti, teorie grafů

## Abstrakt

Pro líné náhodné procházky na konečném souvislém grafu shrnujeme odhad času promíchání \(t_{\mathrm{mix}}(\varepsilon)\) shora pomocí spektrální mezery \(\gamma\) a minima stacionárního rozdělení \(\pi_{\min}\) a porovnáváme přesnost tohoto odhadu na kružnicových a úplných grafech. Tento text zároveň slouží jako ukázka psaní odborného článku v Lunascape Docs: věty a důkazy, diagram v Mermaid, graf ve Vega-Lite a seznam literatury.

**Klíčová slova**: náhodná procházka, čas promíchání, spektrální mezera, Markovův řetězec
