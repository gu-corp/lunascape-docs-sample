# 有限圖上隨機漫步的混合時間

**作者**：架空 太郎（Orbit 研究所）、Jane Example（Example University）
**日期**：2026-09-06 ・ **分類**：機率論、圖論

## 摘要

針對有限連通圖上的延遲隨機漫步，本文整理混合時間 \(t_{\mathrm{mix}}(\varepsilon)\) 可由譜隙 \(\gamma\) 與定常分佈的最小值 \(\pi_{\min}\) 從上方界定的結果，並在環圖與完全圖上比較該評估的精確度。本文同時作為以 Lunascape Docs 撰寫論文的範例，示範定理與證明、以 Mermaid 繪製的圖表、以 Vega-Lite 繪製的圖表，以及參考文獻的寫法。

**關鍵字**：隨機漫步、混合時間、譜隙、馬可夫鏈
