# Véletlen bolyongások keveredési idejéről véges gráfokon

**Szerzők**: Kakū Taró (Orbit Kutatóintézet), Jane Example (Example University)
**Dátum**: 2026-09-06 · **Szakterület**: valószínűségszámítás, gráfelmélet

## Kivonat

Véges összefüggő gráfon vett lusta véletlen bolyongásra áttekintjük a \(t_{\mathrm{mix}}(\varepsilon)\) keveredési idő felső becslését a \(\gamma\) spektrálréssel és a stacionárius eloszlás \(\pi_{\min}\) minimumával, és összehasonlítjuk a becslés élességét körgráfon és teljes gráfon. A dolgozat egyben példa arra, hogyan lehet tanulmányt írni a Lunascape Docs segítségével: tételek és bizonyítások, Mermaid-ábra, Vega-Lite-diagram és irodalomjegyzék.

**Kulcsszavak**: véletlen bolyongás, keveredési idő, spektrálrés, Markov-lánc
