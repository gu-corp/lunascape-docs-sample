# Om blandingstider for tilfældige vandringer på endelige grafer

**Forfattere**: Taro Kakū (Orbit Research), Jane Example (Example University)
**Dato**: 2026-09-06 · **Emner**: sandsynlighedsteori, grafteori

## Resumé

For den dovne tilfældige vandring på en endelig sammenhængende graf gennemgår vi grænsen for blandingstiden \(t_{\mathrm{mix}}(\varepsilon)\) udtrykt ved spektralgabet \(\gamma\) og minimumsværdien af den stationære fordeling \(\pi_{\min}\), og vi sammenligner, hvor skarp vurderingen er på cykliske grafer og fuldstændige grafer. Artiklen tjener samtidig som eksempel på at skrive en artikel i Lunascape Docs: sætninger og beviser, et diagram med Mermaid, en graf med Vega-Lite og litteraturhenvisninger.

**Nøgleord**: tilfældig vandring, blandingstid, spektralgab, Markov-kæde
