# دربارهٔ زمان اختلاط گشت تصادفی روی گراف‌های متناهی

**نویسندگان**: تارو کاکو (پژوهشگاه Orbit)، Jane Example (Example University)
**تاریخ**: ۲۰۲۶-۰۹-۰۶ · **موضوع‌ها**: نظریهٔ احتمال، نظریهٔ گراف

## چکیده

برای گشت تصادفی تنبل روی گراف متناهی همبند، کرانی را که زمان اختلاط \(t_{\mathrm{mix}}(\varepsilon)\) را بر حسب شکاف طیفی \(\gamma\) و کمینهٔ توزیع ایستا \(\pi_{\min}\) از بالا محدود می‌کند مرور می‌کنیم و دقت این برآورد را روی گراف دوری و گراف کامل مقایسه می‌کنیم. این نوشته در عین حال نمونه‌ای از نوشتن مقاله با Lunascape Docs است: قضیه و اثبات، نمودار با Mermaid، نمودار داده با Vega-Lite و شیوهٔ نوشتن منابع.

**کلیدواژه‌ها**: گشت تصادفی، زمان اختلاط، شکاف طیفی، زنجیرهٔ مارکوف
