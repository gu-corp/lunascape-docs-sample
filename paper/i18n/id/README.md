# Tentang waktu pencampuran jalan acak pada graf hingga

**Penulis**: Taro Kakū (Orbit Research), Jane Example (Example University)
**Tanggal**: 2026-09-06 · **Klasifikasi**: teori probabilitas, teori graf

## Abstrak

Untuk jalan acak malas (lazy random walk) pada graf terhubung hingga, kami merangkum batas atas waktu pencampuran \(t_{\mathrm{mix}}(\varepsilon)\) yang dinyatakan melalui celah spektral \(\gamma\) dan nilai minimum distribusi stasioner \(\pi_{\min}\), lalu membandingkan ketajaman batas tersebut pada graf lingkaran dan graf lengkap. Makalah ini sekaligus menjadi contoh penulisan makalah dengan Lunascape Docs: teorema dan bukti, diagram dengan Mermaid, grafik dengan Vega-Lite, serta cara menulis daftar pustaka.

**Kata kunci**: jalan acak, waktu pencampuran, celah spektral, rantai Markov
