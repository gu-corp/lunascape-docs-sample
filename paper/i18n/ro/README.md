# Despre timpii de amestecare ai plimbărilor aleatoare pe grafuri finite

**Autori**: Taro Kakū (Institutul de cercetare Orbit), Jane Example (Example University)
**Data**: 2026-09-06 · **Domenii**: teoria probabilităților, teoria grafurilor

## Rezumat

Pentru plimbarea aleatoare leneșă pe un graf finit conex, sistematizăm marginea superioară a timpului de amestecare \(t_{\mathrm{mix}}(\varepsilon)\) exprimată prin intervalul spectral \(\gamma\) și valoarea minimă a distribuției staționare \(\pi_{\min}\), apoi comparăm precizia estimării pe grafuri ciclice și pe grafuri complete. Lucrarea servește totodată ca exemplu de redactare a unui articol cu Lunascape Docs: teoreme și demonstrații, o diagramă Mermaid, un grafic Vega-Lite și bibliografia.

**Cuvinte-cheie**: plimbare aleatoare, timp de amestecare, interval spectral, lanț Markov
