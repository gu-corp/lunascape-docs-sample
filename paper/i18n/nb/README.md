# Om blandingstider for tilfeldige turer på endelige grafer

**Forfattere**: Taro Kakū (Orbit Research), Jane Example (Example University)
**Dato**: 2026-09-06 · **Emner**: sannsynlighetsteori, grafteori

## Sammendrag

For den late tilfeldige turen på en endelig sammenhengende graf gjennomgår vi hvordan blandingstiden \(t_{\mathrm{mix}}(\varepsilon)\) kan begrenses ovenfra ved spektralgapet \(\gamma\) og minimumsverdien til den stasjonære fordelingen \(\pi_{\min}\), og vi sammenligner hvor skarp vurderingen er for sykelgrafer og komplette grafer. Artikkelen er samtidig et eksempel på hvordan man skriver en artikkel med Lunascape Docs: teoremer og bevis, et diagram laget med Mermaid, en graf laget med Vega-Lite og litteraturhenvisninger.

**Nøkkelord**: tilfeldig tur, blandingstid, spektralgap, Markov-kjede
