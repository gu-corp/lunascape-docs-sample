# 유한 그래프 위 랜덤 워크의 혼합 시간에 대하여

**저자**: 架空 太郎(Orbit 연구소), Jane Example(Example University)
**날짜**: 2026-09-06 · **분류**: 확률론, 그래프 이론

## 요지

유한 연결 그래프 위의 지연 랜덤 워크에 대하여, 혼합 시간 \(t_{\mathrm{mix}}(\varepsilon)\)이 스펙트럼 갭 \(\gamma\)와 정상 분포의 최솟값 \(\pi_{\min}\)으로 위에서 억제된다는 사실을 정리하고, 순환 그래프와 완전 그래프에서 평가의 정밀도를 비교한다. 본고는 Lunascape Docs로 논문을 쓰는 예로서, 정리와 증명, Mermaid를 이용한 다이어그램, Vega-Lite를 이용한 그래프, 참고 문헌의 작성법을 보인다.

**키워드**: 랜덤 워크, 혼합 시간, 스펙트럼 갭, 마르코프 연쇄
