# Про час змішування випадкових блукань на скінченних графах

**Автори**: Таро Каку (Orbit Research), Jane Example (Example University)
**Дата**: 2026-09-06 · **Класифікація**: теорія ймовірностей, теорія графів

## Анотація

Для лінивого випадкового блукання на скінченному зв'язному графі ми впорядковуємо оцінку зверху часу змішування \(t_{\mathrm{mix}}(\varepsilon)\) через спектральну щілину \(\gamma\) та мінімум стаціонарного розподілу \(\pi_{\min}\), а також порівнюємо точність цієї оцінки на циклічних і повних графах. Ця стаття водночас слугує прикладом написання наукової роботи в Lunascape Docs: теореми й доведення, діаграма Mermaid, графік Vega-Lite і список літератури.

**Ключові слова**: випадкове блукання, час змішування, спектральна щілина, ланцюг Маркова
