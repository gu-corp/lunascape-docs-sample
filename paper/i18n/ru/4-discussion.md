# 4. Обсуждение

Верхняя граница из теоремы 3.1 имеет вид времени релаксации \(t_{\mathrm{rel}} = 1/\gamma\), умноженного на \(\log(1/\pi_{\min})\). Второй множитель — это плата за старт из наихудшей возможной точки, и он исчезает, если начинать с распределения, близкого к стационарному. На циклическом графе этот множитель фактически не сказывается, поскольку \(\pi\) равномерно независимо от начальной точки, а разрыв между расстоянием \(\ell^2\) и расстоянием по вариации остаётся порядка \(\sqrt{n}\).

С другой стороны, в сочетании с нижней границей \(t_{\mathrm{mix}}(\varepsilon) \ge (t_{\mathrm{rel}} - 1) \log \frac{1}{2\varepsilon}\) ([1, теорема 12.5]) это помещает время перемешивания между постоянным кратным времени релаксации и его \(\log(1/\pi_{\min})\)-кратным значением. Чтобы сократить этот разрыв, нужен более тонкий анализ, например через явление отсечки (cutoff) [2].

В качестве направлений дальнейшей работы отметим: (i) расширение на необратимые цепи, (ii) оценку \(\pi_{\min}\) для графов с весами на рёбрах, (iii) измерения на графах из реальных данных (например, на дорожных сетях).
