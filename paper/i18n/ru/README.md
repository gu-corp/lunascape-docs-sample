# О времени перемешивания случайных блужданий на конечных графах

**Авторы**: Таро Каку (Orbit Research), Jane Example (Example University)
**Дата**: 2026-09-06 · **Разделы**: теория вероятностей, теория графов

## Аннотация

Для ленивого случайного блуждания на конечном связном графе мы приводим оценку времени перемешивания \(t_{\mathrm{mix}}(\varepsilon)\) через спектральную щель \(\gamma\) и минимум стационарного распределения \(\pi_{\min}\) и сравниваем ее точность на циклах и полных графах. Статья одновременно служит примером написания научной работы в Lunascape Docs: теоремы и доказательства, схема на Mermaid, график на Vega-Lite и список литературы.

**Ключевые слова**: случайное блуждание, время перемешивания, спектральная щель, цепь Маркова
