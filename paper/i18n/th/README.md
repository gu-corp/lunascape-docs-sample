# ว่าด้วยเวลาการผสมของการเดินสุ่มบนกราฟจำกัด

**ผู้เขียน**: Taro Kakū (Orbit Research), Jane Example (Example University)
**วันที่**: 2026-09-06 ・ **สาขา**: ทฤษฎีความน่าจะเป็น, ทฤษฎีกราฟ

## บทคัดย่อ

สำหรับการเดินสุ่มแบบหน่วง (lazy random walk) บนกราฟจำกัดที่เชื่อมโยงกัน บทความนี้เรียบเรียงผลที่ว่าเวลาการผสม \(t_{\mathrm{mix}}(\varepsilon)\) ถูกจำกัดขอบบนด้วยช่องว่างเชิงสเปกตรัม \(\gamma\) และค่าต่ำสุดของการแจกแจงเสถียร \(\pi_{\min}\) แล้วเปรียบเทียบความแม่นยำของขอบเขตนี้บนกราฟวงรอบและกราฟบริบูรณ์ บทความนี้ยังเป็นตัวอย่างการเขียนบทความด้วย Lunascape Docs โดยแสดงวิธีเขียนทฤษฎีบทและบทพิสูจน์ แผนภาพด้วย Mermaid กราฟด้วย Vega-Lite และรายการอ้างอิง

**คำสำคัญ**: การเดินสุ่ม, เวลาการผสม, ช่องว่างเชิงสเปกตรัม, ลูกโซ่มาร์คอฟ
