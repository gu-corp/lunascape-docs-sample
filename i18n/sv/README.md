# Lunascape Docs-exempel

Exempel på vad som kan skrivas med Lunascape Docs utöver manualer: två andra typer — en **Specifikation** och en **artikel** — kompletta med tabeller, diagram, matematik, referenser och översättningar. Välj den du vill läsa.

Båda är rena Markdown-filer på GitHub. Byt språk med 🌐 uppe till höger, och föreslå en ändring från [Redigera] direkt där du läser.
