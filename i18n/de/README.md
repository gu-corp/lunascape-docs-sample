# Lunascape-Docs-Beispiele

Beispiele dafür, was sich mit Lunascape Docs über Handbücher hinaus schreiben lässt: eine **Spezifikation** und ein **Paper**, komplett mit Tabellen, Diagrammen, Formeln, Literaturangaben und Übersetzungen. Wählen Sie eines aus.

Beide sind einfache Markdown-Dateien auf GitHub. Wechseln Sie die Sprache mit 🌐 oben rechts, und schlagen Sie über [Bearbeiten] direkt dort eine Änderung vor, wo Sie gerade lesen.
