# Lunascape Docs minták

Példák arra, mi mindent lehet írni a Lunascape Docs segítségével a kézikönyveken túl: egy **specifikáció** és egy **tanulmány**, táblázatokkal, ábrákkal, képletekkel, hivatkozásokkal és fordításokkal együtt. Válasszon egyet.

Mindkettő egyszerű Markdown-fájl a GitHubon. Váltson nyelvet a jobb felső sarokban lévő 🌐 gombbal, és javasoljon módosítást a [Szerkesztés] gombbal, épp ott, ahol olvas.
