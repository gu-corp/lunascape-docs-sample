# نمونه‌های Lunascape Docs

نمونه‌هایی از آنچه با Lunascape Docs فراتر از دفترچه‌های راهنما می‌توان نوشت: یک **مشخصات فنی** و یک **مقاله**، همراه با جدول‌ها، نمودارها، فرمول‌های ریاضی، منابع و ترجمه‌ها. یکی را انتخاب کنید.

هر دو فایل‌های Markdown ساده روی GitHub هستند. زبان را با 🌐 در گوشهٔ بالا سمت راست تغییر دهید و از [ویرایش] همان‌جا که می‌خوانید تغییری پیشنهاد دهید.
