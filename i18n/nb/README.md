# Lunascape Docs – eksempler

Eksempler på hva du kan skrive med Lunascape Docs utover håndbøker: en **spesifikasjon** og en **artikkel**, komplett med tabeller, diagrammer, ligninger, referanser og oversettelser. Velg en.

Begge er vanlige Markdown-filer på GitHub. Bytt språk med 🌐 øverst til høyre, og foreslå en endring fra [Rediger] der du leser.
