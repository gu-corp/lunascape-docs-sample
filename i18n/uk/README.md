# Приклади Lunascape Docs

Приклади того, що можна написати в Lunascape Docs, окрім посібників: два жанри — **Специфікація** та **стаття** — з таблицями, діаграмами, формулами, списками літератури та перекладами. Оберіть той, який хочете почитати.

Обидва є звичайними файлами Markdown на GitHub. Перемкніть мову за допомогою 🌐 угорі праворуч і запропонуйте зміну через [Редагувати] прямо там, де читаєте.
