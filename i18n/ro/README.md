# Exemple Lunascape Docs

Exemple de ceea ce se poate scrie cu Lunascape Docs în afară de manuale: o **specificație** și o **lucrare**, complete cu tabele, diagrame, ecuații, referințe și traduceri. Alegeți una.

Ambele sunt fișiere Markdown obișnuite pe GitHub. Comutați limba cu 🌐 din dreapta sus și propuneți o modificare din [Editează] chiar acolo unde citiți.
