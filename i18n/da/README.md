# Lunascape Docs-eksempler

Eksempler på, hvad man kan skrive med Lunascape Docs ud over manualer: to typer — en **specifikation** og et **paper** — komplet med tabeller, diagrammer, matematik, referencer og oversættelser. Vælg den, du vil læse.

Begge er almindelige Markdown-filer på GitHub. Skift sprog med 🌐 øverst til højre, og foreslå en ændring fra [Rediger], lige der hvor du læser.
