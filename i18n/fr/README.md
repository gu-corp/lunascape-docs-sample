# Exemples de Lunascape Docs

Exemples de documents réalisables avec Lunascape Docs, au-delà des manuels : deux genres — une **spécification** et un **article** — fournis avec tableaux, schémas, formules, références bibliographiques et traductions. Choisissez celui que vous souhaitez lire.

Les deux sont des fichiers Markdown tels quels sur GitHub. Changez de langue avec le 🌐 en haut à droite, et proposez une correction sur place depuis [Modifier].
