# Contoh Lunascape Docs

Contoh dokumen yang boleh ditulis dengan Lunascape Docs. Selain manual, kami sediakan 2 jenis lagi — **Spesifikasi** dan **kertas kerja** — lengkap dengan jadual, rajah, rumus matematik, rujukan dan terjemahan. Sila pilih yang ingin dibaca.

Kedua-duanya ialah fail Markdown itu sendiri di GitHub. Tukar bahasa dengan 🌐 di bahagian atas kanan, dan cadangkan pembetulan di tempat itu juga melalui [Edit].
