# ตัวอย่าง Lunascape Docs

ตัวอย่างเอกสารที่เขียนได้ด้วย Lunascape Docs นอกเหนือจากคู่มือ มี 2 ประเภท — **ข้อกำหนด** และ **บทความวิชาการ** — พร้อมด้วยตาราง แผนภาพ สูตรคณิตศาสตร์ เอกสารอ้างอิง ไปจนถึงคำแปล เลือกอ่านประเภทที่ต้องการได้เลย

ทั้งสองประเภทเป็นไฟล์ Markdown บน GitHub โดยตรง สลับภาษาได้ด้วย 🌐 ที่มุมขวาบน และแก้ไขพร้อมเสนอการเปลี่ยนแปลงได้ทันทีจาก [แก้ไข] ตรงจุดที่คุณกำลังอ่าน
