# Exemplos do Lunascape Docs

Exemplos de documentos que podem ser escritos com o Lunascape Docs além de manuais: dois tipos — uma **especificação** e um **artigo** — completos com tabelas, diagramas, fórmulas, referências e traduções. Escolha o que quiser ler.

Ambos são arquivos Markdown no GitHub. Troque o idioma com o 🌐 no canto superior direito e proponha uma correção ali mesmo em [Editar].
