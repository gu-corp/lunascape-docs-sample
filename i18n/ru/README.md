# Примеры Lunascape Docs

Примеры документов, которые можно создавать в Lunascape Docs помимо руководств: два вида — **спецификация** и **статья** — с таблицами, схемами, формулами, списками литературы и переводами. Выберите то, что хотите прочитать.

Оба — это обычные файлы Markdown на GitHub. Переключите язык значком 🌐 в правом верхнем углу и предложите правку прямо на месте через [Редактировать].
