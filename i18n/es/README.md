# Ejemplos de Lunascape Docs

Ejemplos de lo que se puede escribir con Lunascape Docs además de los manuales: dos tipos —una **especificación** y un **artículo**— con tablas, diagramas, fórmulas, referencias y traducciones incluidas. Elige el que quieras leer.

Ambos son archivos Markdown tal cual en GitHub. Cambia el idioma con 🌐 en la esquina superior derecha y, desde [Editar], corrígelos y proponlos ahí mismo.
