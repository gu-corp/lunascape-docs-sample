# Esempi di Lunascape Docs

Esempi di ciò che si può scrivere con Lunascape Docs oltre ai manuali: due tipi diversi — una **specifica** e un **articolo** — completi di tabelle, diagrammi, formule, riferimenti bibliografici e traduzioni. Scegli quello che preferisci leggere.

Entrambi sono file Markdown veri e propri su GitHub. Cambia la lingua con 🌐 in alto a destra e, da [Modifica], correggi e proponi le modifiche direttamente sul posto.
