# Примери за Lunascape Docs

Примери за това какво може да се напише с Lunascape Docs освен ръководства: **спецификация** и **научна статия**, заедно с таблици, диаграми, формули, библиография и преводи. Изберете една.

И двете са обикновени Markdown файлове в GitHub. Сменете езика с 🌐 горе вдясно и предложете промяна от [Редактиране] точно там, където четете.
