# Δείγματα Lunascape Docs

Παραδείγματα από όσα μπορούν να γραφτούν με το Lunascape Docs πέρα από τα εγχειρίδια: ένα **έγγραφο προδιαγραφών** και μια **εργασία**, με πίνακες, διαγράμματα, εξισώσεις, βιβλιογραφικές αναφορές και μεταφράσεις. Διαλέξτε αυτό που θέλετε να διαβάσετε.

Και τα δύο είναι απλά αρχεία Markdown στο GitHub. Αλλάξτε τη γλώσσα με το 🌐 πάνω δεξιά και προτείνετε μια αλλαγή από το [Επεξεργασία] εκεί ακριβώς όπου διαβάζετε.
