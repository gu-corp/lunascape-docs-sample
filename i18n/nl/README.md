# Lunascape Docs voorbeelden

Voorbeelden van wat je met Lunascape Docs kunt schrijven, naast handleidingen: twee soorten — een **specificatie** en een **paper** — compleet met tabellen, diagrammen, formules, literatuurverwijzingen en vertalingen. Kies wat je wilt lezen.

Beide zijn gewoon Markdown-bestanden op GitHub. Wissel van taal met 🌐 rechtsboven en stel via [Bewerken] ter plekke een wijziging voor.
