# Lunascape Docs নমুনা

Lunascape Docs দিয়ে যা লেখা যায় তার উদাহরণ, ম্যানুয়াল ছাড়াও ২টি ধরন — একটি **স্পেসিফিকেশন** এবং একটি **গবেষণাপত্র** — টেবিল, চিত্র, গাণিতিক সূত্র, তথ্যসূত্র এবং অনুবাদসহ প্রস্তুত করা হয়েছে। যেটি পড়তে চান তা বেছে নিন।

দুটিই GitHub-এ থাকা সরল Markdown ফাইল। উপরের ডানদিকে 🌐 দিয়ে ভাষা পরিবর্তন করুন, এবং যেখানে পড়ছেন সেখানেই [সম্পাদনা] থেকে সংশোধন করে প্রস্তাব করুন।
