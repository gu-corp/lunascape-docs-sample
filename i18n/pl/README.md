# Przykłady Lunascape Docs

Przykłady tego, co można napisać w Lunascape Docs poza podręcznikami: **specyfikacja** i **artykuł naukowy**, wraz z tabelami, diagramami, wzorami matematycznymi, bibliografią i tłumaczeniami. Wybierz jeden.

Oba są zwykłymi plikami Markdown na GitHub. Przełącz język za pomocą 🌐 w prawym górnym rogu i zaproponuj zmianę z poziomu [Edytuj] dokładnie tam, gdzie czytasz.
