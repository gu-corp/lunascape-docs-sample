# Lunascape Docs -esimerkit

Esimerkkejä siitä, mitä Lunascape Docs -sovelluksella voi kirjoittaa manuaalien lisäksi — kaksi tyyppiä — **määrittely** ja **paperi** — mukanaan taulukot, kaaviot, matematiikka, lähdeviitteet ja käännökset. Valitse se, jonka haluat lukea.

Molemmat ovat sellaisenaan Markdown-tiedostoja GitHubissa. Vaihda kieli oikeasta yläkulmasta 🌐-kuvakkeella ja ehdota muutosta [Muokkaa]-painikkeella siinä samassa, missä luet.
