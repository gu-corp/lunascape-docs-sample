# Lunascape Docs नमूने

Lunascape Docs से लिखे जा सकने वाले दस्तावेज़ों के उदाहरण। मैनुअल के अलावा 2 प्रकार — एक **विनिर्देश** और एक **शोधपत्र** — तालिकाओं, आरेखों, गणितीय सूत्रों, संदर्भों और अनुवादों समेत तैयार किए गए हैं। जिसे पढ़ना चाहें, उसे चुनें।

दोनों ही GitHub पर मौजूद Markdown फ़ाइलें ही हैं। ऊपर दाईं ओर 🌐 से भाषा बदलें, और जहाँ आप पढ़ रहे हैं वहीं [संपादित करें] से बदलाव का प्रस्ताव दें।
