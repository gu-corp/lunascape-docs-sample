# Ví dụ về Lunascape Docs

Đây là những ví dụ về tài liệu có thể viết bằng Lunascape Docs. Ngoài sổ tay hướng dẫn, chúng tôi còn chuẩn bị 2 thể loại khác — **bản đặc tả** và **bài báo** — bao gồm cả bảng, sơ đồ, công thức toán, tài liệu tham khảo và bản dịch. Hãy chọn cái bạn muốn đọc.

Cả hai đều chính là các tệp Markdown trên GitHub. Chuyển đổi ngôn ngữ bằng 🌐 ở góc trên bên phải, và đề xuất chỉnh sửa ngay tại chỗ từ [Chỉnh sửa].
