# דוגמאות של Lunascape Docs

דוגמאות למה שאפשר לכתוב ב-Lunascape Docs מעבר למדריכים — שני סוגים נוספים: **מפרט** ו**מאמר** — הכוללים טבלאות, תרשימים, נוסחאות, מקורות ואף תרגום. בחרו את מה שתרצו לקרוא.

שניהם קובצי Markdown עצמם ב-GitHub. החליפו שפה באמצעות 🌐 בפינה הימנית העליונה, ותקנו והציעו שינוי במקום מתוך [עריכה].
